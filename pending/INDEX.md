# 暂缓收录作品（pending）

本目录登记**仍在著作权保护期内**或**版权状态待确认**的作品。

这些篇目属于《义务教育语文课程标准（2022年版）》附录1 的推荐范围，
但因著作权未进入公有领域，**本仓暂不收录原文**，以确保法律风险为 0。

## 说明

- 课标 135 篇中，绝大部分作者（骆宾王、李白、杜甫、苏轼、辛弃疾、
  陶渊明、范仲淹、欧阳修、王安石、朱熹、陆游、李清照、文天祥、方志敏、
  朱自清、冰心、徐志摩等）均已逝世**逾五十年至千余年**，著作权保护期
  早已届满，原文属**公有领域**，可自由收录。

- 需注意：我国《著作权法》对**自然人**作品的保护期为作者终生及死后 50 年，
  对**法人作品**为发表后 50 年。1911 年（或更早）发表且作者已逝世满 50 年的
  作品，均已进入公有领域。

- 若需收录 `pending/` 中的作品，应先确认版权状态并取得授权，
  然后将文件移入 `poems/` 并把 frontmatter 的 `license` 改为实际许可。

## 不得混入

`tools/validate.py` 会强制校验：

> `license != public-domain` 的篇目**不得**出现在 `poems/` 目录下。

若混入了保护期内的作品，校验会直接失败。这是为了确保本仓对外
发布时版权状态清晰可查。
