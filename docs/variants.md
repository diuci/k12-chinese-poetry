# 异文考证

古文在传抄、翻刻、入选集、进教材的每一步都会产生用字差异。这一节规定：**碰到版本差异时怎么办、
要写下什么、网页上给读者看什么。**

## 0. 为什么不能只给一个「标准答案」

学生按教材写才算对——考试是按教材算的。但只印一个写法，读者会以为别本都是错字，
而实际上很多「别本」是更早、更权威的版本。

所以本仓的口径是：**正文取教材本，别本全部列出，每一处写清依据。**
不静默择一，不把异文写成错字。

## 1. 一条异文必须有四样东西

| 项 | 内容 | 为什么必须有 |
|---|---|---|
| 仓内用字 | 我们正文里写的那个 | 读者要知道我们取哪个 |
| 别本用字 | 另一个写法 | 异文本身 |
| **出处** | 哪个版本、哪本书、哪个页（能点回去核对） | 没有出处的异文等于「我听说」 |
| **取舍** | 为什么取这个，一句话 | 不写理由，读者无法判断我们是不是随便挑的 |

篇内格式（「## 异文」小节，一条一行，出处与取舍可以换行续写）：

```
- 「征帆去棹」：一作「归帆去棹」。
  出处：统编教材必修下册第 15 课作「归帆」（见 data/textbook-attestations.json）；
        维基文库《桂枝香·金陵怀古》正文作「征帆」（《白香词谱笺》本）。
  考证：教材本改「征」作「归」，与「去棹」意思相复；古籍本多作「征帆」。
  取舍：正文取教材本「归帆」——考试按教材算；古籍本的写法留在本节。
```

## 2. 版本来源的优先级

按「考试按谁算」排序，不按「哪个更古老」排序：

1. **统编教材**（人教社官方，见 [sources.md](sources.md) 的 S10）——考试按它算，正文取它。
2. **教材所据的古籍版本**（《史记》《文选》《四部丛刊》本等）——决定「教材为什么这么写」。
3. **总集本**：《四库全书》本、《全唐诗》《全宋词》、《词综》《白香词谱》——异文最常从这里出来。
4. **注本 / 校本**：《论语正义》、《文选》李善注、各家校勘记——能给出「为什么作某字」的理由。
5. 其他别本：只列，不取。

## 3. 考证怎么做（可复现，不靠灵感）

1. 取机器找到的异文线索：tools/check-text-sources.py 解析维基文库 wikitext 里的
   {{另|甲|乙}} 夹注，写进 data/text-sources.json 的 variants（含页名与上下文）。
2. 取教材用字：tools/check-textbook.py 写进 data/textbook-attestations.json。
3. 两处不一致的篇目，逐处去查版本源：ctext（S11）的并列版本、四库本、总集本，
   记下**每一本各作什么**。
4. 检索这条异文有没有校勘讨论（论文、校勘记）。**有依据就写出处；没有就写「未见校勘依据，仅列别本」**——
   不许编一个理由。
5. 结论写进篇内「异文」小节，按上面那张四样东西的格式。

## 4. 不许做的事

- **不许静默择一**：发现了异文却不写下来，等于把它藏起来。
- **不许把异文写成错字**：别本用字不是错字，除非有校勘依据说明它是讹字。
- **不许抄商业站的校勘结论当自己的考证**：古诗文网等受著作权保护，可以引用出处，结论要自己写。
- **只有一条来源证据的改动，不动正文**：登记进 known-defects.json，等第二条来源。
  镜像来源尤其要防——它已抓到并非统编简体原文（见 sources.md 的 S10 红旗）。

## 5. 网页上给读者看什么

篇页里「异文」是一个独立小节，每条按「仓内用字 / 别本 / 出处 / 取舍」四段显示，
出处带可点的链接。默写练习里出现异文的句子，在答案旁标一句「教材本作某」，
不让读者在练习里被别本带偏。

台账里对这一项有计数：**有出处的异文条目数 / 有取舍的异文条目数 / 无出处的条目数**
（data/ledger.json）。无出处的条目数不为零时，这一项不算完成。
## 5. 台账怎么数异文（这一条改过一次，改的原因是数字是虚的）

以前「## 异文」小节里**每一条 bullet 都算一条异文**。结果版权说明、校勘待办、通假字解释
也被算进去，把分母撑虚：数字看着像「考证做了 513 条」，其实有 197 条根本不是异文。

现在的口径：只有断言「这里有另一种写法」的条目才算异文（认这些标记：
一作、别本、他本、另一本、版本作、来源页作、夹注、异体、旧本作、通行本作、误作）。
剩下的不静默丢掉——台账单列「异文小节里的非异文条目」，让人看得见这一节里还混着什么，
该挪去注释的挪去注释，该删的删，但必须先看得见。

| 口径 | 条目数 | 带出处 | 带取舍 | 缺出处 |
|---|---|---|---|---|
| 旧口径（全算） | 513 | 365 | 106 | 148 |
| 现口径（只算真异文） | **316** | **218** | **92** | **98** |

另有 197 条不是异文的说明留在「## 异文」小节里，台账单列。

补出处的工具 `tools/enrich-variants.py` 只做三件事，每条都有坏例子守着：
提到「来源页／维基文库」的补这一篇实际比对过的那一页的链接；自己点了某本书名字的，出处就记那本书（不许换成维基文库）；
理由是「与教材一致」的，出处写 frontmatter 记录的册次，**不许编课号**。已经有出处的一律不重复补。
## 6. 没有写「取舍」的条目，默认是什么——以及这个默认怎么验

台账里「带取舍」的只有 161 条，另有 237 条没有取舍。这不是漏写，是一条默认口径：

> **异文只登记，正文不改。** 仓内用字以统编教材与来源页主文为准；只有写明「取舍」的条目，才是这一处真做过选择。

`enrich-variants.py` 的第一条规矩是「不替人做取舍」——给这 237 条批量补一句「从教材」，
等于替没做过判断的地方编一个判断出来，比空着更糟。

但默认口径不能只是嘴上说。`tools/check-variant-defaults.py` 把它变成可核对的断言：

> 对每一条没有取舍的异文条目，取出它断言的别本写法。如果**别本写法在仓内正文里、
> 而条目引的那句仓内用字反而不在正文里**——那说明这一处其实换过字，只是没写下来。

当前结果：判了 294 条，**违规 0 条**。也就是说，仓里没有任何一处正文跟着登记的别本走。

护栏自带 4 个坏例子：默认口径成立的不能报；真换过字的必须抓到；
正文里另有这个字但仓内那句也在正文里的（巧合）不能报；没有别本断言的条目不判。

站点把这条默认直接写在 异文 一节开头，学生看得见，不用去翻文档。
