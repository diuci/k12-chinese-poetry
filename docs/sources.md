## 各来源的使用边界

### S1 — 教育部课程标准（框架权威）

《义务教育语文课程标准（2022年版）》由教育部制定，附录1
「优秀诗文背诵推荐篇目」列出 **135 篇（段）**：

- **1–6 年级 75 篇**（全部为诗歌）
- **7–9 年级 60 篇（段）**（除诗歌外含短篇散文）

完整清单见 [syllabus-2022.md](syllabus-2022.md)。本仓以此为**唯一收录框架** ——
不收框架外作品。

> **口径提示**：课标**正文**第四学段表述为「背诵优秀诗文 80 篇（段）」，
> 而**附录 1** 列出 135 篇。本仓以附录 1 为准（附录是具体篇目清单），
> 并在 `docs/index.md` 说明这一差异。

### S2 — 人民教育出版社（册次权威）

[pep.com.cn](https://www.pep.com.cn/) 公布的统编语文教材目录，用于确定
每篇的 `grade`（年级）与 `volume`（册次）。

**使用边界**：仅取**元数据**（册次、课题号），**不复制教材正文与注释**。

### S3 / S4 — chinese-poetry（正文来源）

MIT 许可，可商用。提供 5.5 万首唐诗、26 万首宋诗、2.1 万宋词及诗经、
楚辞、论语等。字段含 `title` / `author` / `paragraphs`，宋词另有
`rhythmic`（词牌）、唐诗另有 `strains`（平仄）。

**使用边界**：作为**原文字句的初稿来源**。入库前必须与 S1（是否该收）
和 S2（册次）核对，并用字以人教社教材为准。

> ⚠️S3 数据来自互联网爬取，可能存在异文。**发现用字差异时以教材为准**，
> 并在 `PROVENANCE.md` 记录差异。

### S5 — 商业站（仅比对，不复制）

古诗文网等提供注音、译文、赏析。**这些内容受著作权保护，本仓不复制。**

**使用边界**：仅在 S3 数据缺失或存疑时，人工**比对**用字差异，
**不摘抄**译文与赏析。本仓的注释/译文/赏析**全部自行撰写**。

### S6 — 教研整理清单（仅参考）

网络流传的「60 篇 / 72 篇 / 47 篇」等清单版本众多、常有错漏。
**使用边界**：仅用于交叉验证，不作为权威依据。

### S7 — 中考真题（高频标注）

用于给篇目打 `exam_freq` 分值，帮助学习者聚焦高频考点。
**使用边界**：仅记录篇目名与出处，不转载试题全文。

### S8 — Unicode Unihan（站点拼音注音）

站点的汉字拼音取自 [Unicode Unihan 数据库](https://www.unicode.org/Public/UCD/latest/ucd/)
的 `kMandarin` 字段，该字段读音来自**《通用规范汉字字典》**
（商务印书馆辞书研究中心编，2013），与我国语文教学的通用读音一致。

| 项 | 说明 |
|---|---|
| 许可 | [Unicode License](https://www.unicode.org/license.txt)，可自由使用与再分发 |
| 规模 | 4.4 万字；本仓 1862 个用字 **100% 覆盖** |
| 多音字 | 取第一个主读音。若需按语境修正，直接改 `data/pinyin.txt`（该文件已提交） |
| 获取 | `python tools/gen-pinyin.py --fetch`（一次性下载 Unihan.zip，约 8MB） |

**为什么要引外部数据**：手写拼音表必然有漏字与错误（初版手写表覆盖率仅 21%）。
Unihan 是 Unicode 官方数据，权威、完整、可自动化，且许可允许商用。

## 交叉校验流程

```
S1 课标清单（135 篇，必须全收）
  ↓ 逐条比对，确认「收哪些」
S2 册次归属（定 grade / volume）
  ↓ 正文取字
S3 MIT 开源库（提供初稿原文）
  ↓ 存疑时比对
S5 商业站（仅比对用字差异，不复制）
  ↓ 定稿前
自校：用字以人教社教材为准（树阴/树荫、曈曈/瞳瞳、暖/ 煖 等）
  ↓ 全部通过
写入 PROVENANCE.md 台账 + frontmatter source 字段
```

**校验由 `tools/validate.py` 强制执行**，缺台账字段即构建失败。
