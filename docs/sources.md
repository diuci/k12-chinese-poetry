## 各来源的使用边界

### S1 — 教育部课程标准（框架权威）

《义务教育语文课程标准（2022年版）》由教育部制定，附录1
「优秀诗文背诵推荐篇目」列出 **135 篇（段）**：

- **1–6 年级 75 篇**（全部为诗歌）
- **7–9 年级 60 篇（段）**（除诗歌外含短篇散文）

完整清单见 [syllabus-2022.md](syllabus-2022.md)；高中部分见 [syllabus-2017.md](syllabus-2017.md)。
本仓以课标附录为**主要收录框架**：课标列出的必须收全。

框架外只有一类例外——**教材拓展**：统编教材课本里实际有、但课标附录未列的篇目
（如七下课外诵读《竹里馆》《晚春》、八下《北冥有鱼》《石壕吏》）。这类篇目收录，
但在台账里单独标注为「教材拓展」，不混进「课标必背」。除此之外不收框架外作品。

> **口径提示**：课标**正文**第四学段表述为「背诵优秀诗文 80 篇（段）」，
> 而**附录 1** 列出 135 篇。本仓以附录 1 为准（附录是具体篇目清单），
> 并在 `docs/index.md` 说明这一差异。

### S2 — 人民教育出版社（册次权威）

[pep.com.cn](https://www.pep.com.cn/) 公布的统编语文教材目录，用于确定
每篇的 `grade`（年级）与 `volume`（册次）。

**使用边界**：仅取**元数据**（册次、课题号），**不复制教材正文与注释**。

### S3 / S4 — chinese-poetry（正文来源）

MIT 许可，可商用。提供 5.5 万首唐诗、26 万首宋诗、2.1 万宋词及诗经、
楚辞、论语等。字段含 `title` / `author` / `paragraphs`，宋词另有
`rhythmic`（词牌）、唐诗另有 `strains`（平仄）。

**使用边界**：作为**原文字句的初稿来源**。入库前必须与 S1（是否该收）
和 S2（册次）核对，并用字以人教社教材为准。

> ⚠️S3 数据来自互联网爬取，可能存在异文。**发现用字差异时以教材为准**，
> 并在 `PROVENANCE.md` 记录差异。

### S5 — 商业站（仅比对，不复制）

古诗文网等提供注音、译文、赏析。**这些内容受著作权保护，本仓不复制。**

**使用边界**：仅在 S3 数据缺失或存疑时，人工**比对**用字差异，
**不摘抄**译文与赏析。本仓的注释/译文/赏析**全部自行撰写**。

### S6 — 教研整理清单（仅参考）

网络流传的「60 篇 / 72 篇 / 47 篇」等清单版本众多、常有错漏。
**使用边界**：仅用于交叉验证，不作为权威依据。

### S7 — 中考真题（高频标注）

用于给篇目打 `exam_freq` 分值，帮助学习者聚焦高频考点。
**使用边界**：仅记录篇目名与出处，不转载试题全文。

### S8 — Unicode Unihan（站点拼音注音）

站点的汉字拼音取自 [Unicode Unihan 数据库](https://www.unicode.org/Public/UCD/latest/ucd/)
的 `kMandarin` 字段，该字段读音来自**《通用规范汉字字典》**
（商务印书馆辞书研究中心编，2013），与我国语文教学的通用读音一致。

| 项 | 说明 |
|---|---|
| 许可 | [Unicode License](https://www.unicode.org/license.txt)，可自由使用与再分发；再分发时必须保留原始版权头 |
| 合规 | `data/unihan/Unihan_Readings.txt` 保留 Unicode 原始文件头（© Unicode, Inc. 与条款链接），**不得裁剪** |
| 规模 | 4.4 万字；本仓 1862 个用字 **100% 覆盖** |
| 多音字 | 取第一个主读音。若需按语境修正，直接改 `data/pinyin.txt`（该文件已提交） |
| 获取 | `python tools/gen-pinyin.py --fetch`（一次性下载 Unihan.zip，约 8MB） |

**为什么要引外部数据**：手写拼音表必然有漏字与错误（初版手写表覆盖率仅 21%）。
Unihan 是 Unicode 官方数据，权威、完整、可自动化，且许可允许商用。

### S9 — 维基文库（公有领域正文的独立交叉核对）

[zh.wikisource.org](https://zh.wikisource.org/) 上的公有领域文本，用来**独立复核**仓内正文，
不是正文的初稿来源。工具：`tools/check-text-sources.py`，产物 `data/text-sources.json`。

| 项 | 说明 |
|---|---|
| 做法 | 每篇取「必背名句」逐句去来源页比对；繁→简用 OpenCC `TSCharacters` 字表，**只用于比对，不改仓内正文** |
| 匹配强度 | 整句直接命中 → 夹注打断（head/tail）→ 只认顺序的子序列 → 相似度 ≥0.82 的近似 |
| 夹注 | 来源页里的「一作某」是异文线索，不是错误，逐条写进篇内「异文」小节 |
| 强制页名 | `data/source-overrides.json`：有些篇目按标题搜不到正确的页（页名用旧称、带作者、带首句、或按卷/章分页），写死页名并说明为什么 |
| 跨页合并 | 合选类篇目（《论语》十二章、《孟子》三则、古代文论选段）没有单页收全，`union: true` 把多页正文合并后再比对 |
| 过期检查 | 强制页名这张表也会过期：篇目改名或删掉后键还留着，就会静默地不生效，工具会点名 |

**为什么必须独立核对**：S3 是爬来的开源库，S5 是商业站（不许复制）。
只靠这两条来源写正文，错了也没有第二条腿站着。
谏逐客书就是这条核对抓出来的：必背名句与同篇全文自相矛盾（见该篇「旧文本裁定」）。

### S10 — 统编教材：册次与教材用字的证据

教材这一层要回答的只有两个问题：**这篇在哪册第几课**、**教材这里写作哪个字**。

| 项 | 说明 |
|---|---|
| 主来源 | 人教社官方 [stkw.pep.com.cn](https://stkw.pep.com.cn/xzzq/ckda/gyxxrwdy/) 《高中语文学习任务导引》必修上册、必修下册、选择性必修上/中/下 **五册参考答案 PDF** |
| 辅助来源 | 统编课文朗读页镜像 `yw.suyang123.com`（课文原文 + 带课号的目录） |
| 用途 | 定 `volume`（册次与课号）；核对教材用字 |
| 硬边界 | 只取「教材这里写作某字」这一件事。教材的**注释、译文、赏析、活动设计一个字都不许进仓** |
| 工具 | `tools/check-textbook.py`，产物 `data/textbook-attestations.json` |
| 缓存纪律 | 抓下来的课文页只留在本地 `data/textbook-cache/`，已写进 `.gitignore`。仓里只留**结论**（篇目、URL、对上几句、差在哪个字），不留整页副本——整页里带着教材的注释与译文 |

**为什么主来源是官方参考答案而不是镜像**：镜像是第三方抓的，已经抓到它并非统编简体原文——
《归去来兮辞》那一页里出现「遊」「邱」（「经丘」写作「经邱」），那是繁体本的用字。
所以**每一处按教材改正文之前，必须有第二条独立来源**（官方参考答案、或另一个公有领域版本）。
只有镜像一条证据的改动，登记进登记表，不动正文。

### 统编教材有两个版本：2018 版与 2024 修订版

统编三科教材 2018 年秋季起逐年铺开；2024 年秋季起初中起始年级改用修订后的统编教材，课文有增删，课号跟着移动。
仓里 `volume` 记的是**学生现在用的那一版**（现行目录），不是 2018 版。

七年级上册第三单元实测对照：

| 2018 版 | 现行（2024 修订） |
|---|---|
| 9 从百草园到三味书屋 | 9 从百草园到三味书屋 |
| 10 再塑生命的人 | **10 往事依依（新增）** |
| 11 《论语》十二章 | 11* 再塑生命的人 |
| — | 12 《论语》十二章 |

右列不是抄来的说法：仓里拉的目录表 `data/textbook-lessons.json` 七年级上册里就是「10往事依依 / 11*再塑生命的人 / 12《论语》十二章」。
这一条直接决定《论语》十二章在统编教材里是第 12 课——课号差一位，背后是整册课文增删。

同一份整理目录记下的七上整册变化（用来确认「哪一版有哪一课」，正文一个字不取）：
新增《往事依依》《回忆我的母亲》《梅岭三章》《我的白鸽》《大雁归来》《小圣施威降大圣》；
删除《植树的牧羊人》《走一步，再走一步》《动物笑谈》《天上的街市》；
「名著导读」改为「整本书阅读」，删去《白洋淀纪事》《湘行散记》《猎人笔记》《镜花缘》；
第 4 课「古代诗歌四首」里《观沧海》与《闻王昌龄左迁龙标遥有此寄》互换位置。
出处：初中语文教研站整理的 2024 秋七上目录（http://www.tzjtzy.cn/studio/index.php?r=studio/post/view&sid=649&id=6711）。
属 S6 级来源：只用来确认目录结构，不引用它的任何文字。

**口径三条：**

1. 册次以现行统编目录为准，仓里 `volume` 不许写旧版课号；
2. 一篇换过册次的，必须在篇内「收录范围」写明从哪一册挪到哪一册、依据哪一版目录；
3. 不许因为「2018 版没有这一课」就把一篇标成「统编教材未收」。未收的判据只有一条：现行目录里找不到这篇。

**已知风险：** 学生手上可能是 2018 版旧书，同一篇课号不同。所以站点显示册次，不把课号当硬信息显示；
真要显示课号，必须同时标出是哪一版目录。

**高中五册另说。** 高中的册次与课号来自人教社官方《高中语文学习任务导引》参考答案（S10 主来源），
仓里 27 条课号有官方印证。高中是否另有修订版，目前没核到证据，不下结论。

### S11 — 中国哲学书电子化计划（文言经典的第二条腿）

[ctext.org](https://ctext.org/) 收《论语》《孟子》《老子》《庄子》《礼记》《吕氏春秋》等，
每段下面并列多个版本（钦定四库全书本、注疏本、正义本），适合给高中那 32 篇文言做二次核验。

**使用边界**：只用于比对字句与取异文线索，正文与注释仍是我们自己写的。
该站明确反对批量抓取（要求机构订阅），所以**只按需取页、不批量爬**。

## 来源分级：什么问题问谁

「哪个来源最权威」没有统一答案，要按问题分层。问错了对象，答案再权威也没用：
古籍版本不能回答「教材第几课」，教材也不能用来定古籍原貌。

| 要回答的问题 | 问谁 | 为什么是它 |
|---|---|---|
| 收不收这篇 | S1 课标附录（135 篇 / 72 篇） | 考试范围就是按它定的 |
| 在教材哪册第几课 | S10 人教社官方参考答案 | 出版者自己公布的课号 |
| 教材里写作哪个字 | S10 官方 + 第二条公有领域版本 | 学生按教材写才算对 |
| 古籍原文长什么样 | S9 维基文库（四库全书本、总集本）+ S11 ctext | 公有领域、可溯源、带版本夹注 |
| 有没有异文 | S9 的 `{{另|甲|乙}}` 夹注 + S11 并列版本 | 异文必须写下来，不许静默择一 |
| 默写按哪一份清单 | 课标 2017 附录（72 篇）+ 按届区分 | 见 [change-process.md](change-process.md) 的口径 |

### 维基文库的异文是结构化的，以前我们没读它

维基文库正文里的异文写成模板：`{{另|三|吳}}` 表示正文作「三」、另一本作「吳」。
《望海潮》一页里这样的夹注有 8 处：三/江、吳/湖、十/千、萬/里、霜雪/雪屋、嘉/佳、管/笛篴、醉/時。

`tools/check-text-sources.py` 取的是**渲染后的正文**，而渲染时异文被放进一个鼠标悬停才显示的
`<span class="variant-text">` 提示里——剥掉标签就只剩主文，**异文全丢了**。
台账里「200 篇无异文记录」有相当一部分不是「没有异文」，是**我们没去读**。
修法：改取 `prop=wikitext`，把 `{{另|甲|乙}}` 解析成异文记录（P10）。

## 交叉校验流程

```
S1 课标清单（135 篇，必须全收）
  ↓ 逐条比对，确认「收哪些」
S2 册次归属（定 grade / volume）
  ↓ 正文取字
S3 MIT 开源库（提供初稿原文）
  ↓ 存疑时比对
S5 商业站（仅比对用字差异，不复制）
  ↓ 存疑时比对
S9 维基文库（公有领域正文，逐句独立复核 → data/text-sources.json）
  + S11 ctext（文言经典并列版本，按需取页）
  ↓ 教材层
S10 人教社官方参考答案（册次、课号、教材用字）→ data/textbook-attestations.json
  ↓ 定稿前
自校：用字以教材为准，但每一处改动要有第二条来源；只有一条证据的登记进登记表，不动正文
  ↓ 全部通过
写入 PROVENANCE.md 台账 + frontmatter source 字段
```

**校验由 `tools/validate.py` 强制执行**，缺台账字段即构建失败。

## 版权：逐篇核验，不靠口头承诺

我们不对「风险」做绝对化表述。能说的是：每一篇的公有领域状态都有可核验的证据，
并且有一条脚本在把关。

| 内容 | 版权状态 | 依据 | 本仓处理 |
|---|---|---|---|
| 古诗文原文 | 公有领域 | 作者卒年 ≤ 当前年 − 50（《著作权法》自然人作品保护期） | 自由收录，frontmatter 记 `authorDied` |
| 作者不详的《诗经》、乐府、民歌 | 公有领域 | 成书年代上限 `authorEraEnd` | 自由收录 |
| 注释 / 译文 / 赏析 | 我们的创作 | 自行撰写，不摘抄商业站 | CC BY 4.0 |
| 选篇编排（取舍与顺序） | 我们的原创 | — | CC BY 4.0 |
| 课标附录 1 清单 | 政府文件 | 教育部公开发布 | 整理版有我们版权 |
| 仍在保护期内的现当代作品 | 受保护 | 卒年 > 当前年 − 50 | 不收录原文，登记在 `pending/` |

**脚本强制**：`tools/validate.py` 第 8 项逐篇核验卒年，不满足即构建失败；
`python tools/validate.py --selftest` 用一个 1999 年卒的假作者验证这条规则真的会拦。
作者卒年总表见 [`data/authors.json`](../data/authors.json)，
