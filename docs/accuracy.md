# 内容准确性与免责（内容仓侧）

这一页写的是**我们核对到了哪一步**，不是「我们保证没错」。
站点上那一页（`/accuracy`）由 `k12-site/tools/build-site.py` 从台账当场生成，数字不会写死过期；
这一页写的是口径与方法，数字以 `data/ledger.json` 与 `docs/audit.md` 为准。

## 我们对外承诺的口径

1. **收哪些篇**只认课标；**哪一册第几课、教材用哪个字**只认人教社公开页面；
   **古籍原文与异文**认维基文库与中国哲学书电子化计划。
2. **教材版为准 + 附异文清单**，不静默择一。改正文之前必须有第二条独立来源；
   只有镜像证据的改动只登记、不改正文。
3. **没核到就写没核到。** 缺出处的异文条目一律写明「出处：仓内没核到」。
   把「没核到」写成「有出处」等于编造，这一条没有例外。
4. **注释、译文、赏析是我们自己写的**（cc-by-4.0），不是教材里的，也不是教研结论。
   引用本篇原文必须一字不差——引错原文比缺出处更严重，因为那是拿一句不存在的话教给学生。
5. 原文只收**作者卒年 + 50 年已届满**的；这条是 `tools/validate.py` 在跑的规则，不是文档里的说法。

## 核对是怎么做的

- 把仓内每一篇的**句子**（不是整段）剥掉标点，拿去来源页里逐句找；
- 来源页繁体先过一遍繁简转换表再比（不转会造出假「对不上」）；
- 来源页的「一作某」夹注从正文里剥出来，单独登记成异文；
- **搜到一句话不等于找到了来源**：来源页必须装得下这篇正文才算；
- 页坏（生僻字残迹、脚注数字残迹、版权提示插在正文中间）**往往只是渲染坏了**，
  wikitext 可能干净——先怀疑页，不急着改正文。

### 核对单位曾经错过一次（已修）

`tools/check-text-sources.py` 以前只核 `lines`。对长诗与散文，`lines` 就是必背名句：
离骚核的是 4 句、答司马谏议书核的是 6 句，而仓里真正发出去的正文另有 26 联、4 段——
**那部分从没进过这道核对**，台账上「逐句全对上」因此是半真半假的。

现在改成：`lines` 与 `fullLines` 合并，并按句末点号切成句子再比。
散文的 `fullLines` 是整段（答司马谏议书 4 段、每段上百字），整段比对差一个字就整段不算对上，
所以必须切到句子。改完之后核对的句子数从约 900 句涨到约 1,900 句，
**全对上的篇数下降是预期的**——那是把原来没查的部分查了。

### 比对里曾经有一档「像就算对上」（已撤）

`line_in()` 原先退到最后一档：`difflib` 相似度 ≥ 0.82 就返回 `near`，算「对上了」。这一档已撤。
撤它的理由不是「它已经骗过了谁」，是**它能凭空造出命中**：只差一个字的两行相似度 0.9，
一句页里根本没有的诗就会被算成「全对上」。这种出口留着，早晚会用到不该用的地方。

撤掉那一档之后全仓重跑，档位数字与撤之前逐字相同——也就是说那一轮没有哪一篇是靠相似度蒙过去的；
这句话是数出来的，不是推断。撤除那一轮记的是 215 与 36；当场数当前产物（`data/text-sources.json` 的 `stats`）：
215 全对上 / 36 部分对上 / 0 一句都对不上 / 1 核过没有正文页（相加 = 252 ✓）。中间它变成过 214 与 37：
`verify-variant-claims.py --refresh` 把一篇的异文补上了出处，那一篇就挪回「全对上」。这四个数现在由审计当场比对，不许与产物不一致。
差得少的句子照样进 `miss` 列表，`nearest` 把页里最像的那行连同相似度一起写出来，给异文登记用——
但它不再计入「对上」的分子。`--selftest` 的坏例 8 盯着这一处：「城阙辅三秦风烟望五津」对着
页里的「城阙辅三秦风烟望五州」（相似度 0.9）必须报没对上。

**顺带记一件我自己查错的事**：起疑《送杜少府之任蜀州》的来源页《全蜀藝文志 (四庫全書本)/卷20》，
我直接取 wikitext 搜「城阙辅三秦」「与君离别意」，一个都没找到，差点写下「这页根本没有这首诗」。
搜错的是我自己：wikitext 是繁体（「城闕輔三秦」），拿简体串去搜当然找不到。改用工具同一套 `clean()`
之后当场数：页里作「杜少府之任蜀州 王勃 城阙辅三秦 风烟望五津 与君离别意 同是宦游人 海内存知己
天涯若比邻 无为在岐路 儿女共沾巾」，四句全 `exact`。**「我搜不到」不等于「页里没有」**——
这一条写在这里，是因为它和「空过的检查比没有检查更危险」是同一件事。

## 同一个字的另一种写法：认，但不许瞎认

来源页写作「未甞」「山隂」「修脩稧」「靑」「髙」「衞」，我们写作「未尝」「山阴」「修禊」「青」「高」「卫」。
不认这些写法，工具就把「页里明写着这一句」报成「我们对不上」——那是工具的脆，不是内容的错。

所以比对时认一批「同一个字的另一种写法」（`check-text-sources.py` 的 `VARIANT_GLYPHS`）。
每一对都必须在来源页上亲眼看到，并且过一道自检：**两边的 Unihan `kMandarin` 读音必须有交集**。

这道自检当场拦下了我自己加的一对：`彊` 在 Unihan 里读 jiàng、`强` 读 qiáng，
不能断定是同一个字，所以谏逐客书那一句留在「没对上」里，作为异文登记。
同样被明确排除的还有义近字与真异文：說/悅、知/智、蔽/敝、渡/度、歧/岐、欤/与、那/哪、己/已——
**把真异文抹平成「同一个字」，比查不出来更糟**，因为那会让读者以为已经核过了。

试过现成的异体字表（Unicode Unihan），结论是这条路给不出我们要的对子，已放弃：
异体关系写在 `Unihan_Variants.txt` 的 `kSemanticVariant` 等字段里，而 `kSemanticVariant` 正是必须排除的那一类——
按它合并会把 說/悅、知/智 一起抹平；`甞` 的 `kSemanticVariant` 指向的是另一个字（U+83D1），不是 `嘗`。
所以这张表只能自己建、自己一条条在页上验，工具 `build-char-variants.py` 连同它的产物已从仓里删掉：
**跑不过自己自检的工具留在仓里，比没有工具更危险。**

## 网络失败不是内容问题

维基文库被连着问几百次会直接拒连接（WinError 10061）。以前一次失败就记「找不到来源页」，
台账上凭空多出 20 篇「没有来源」。现在 `http_json()` 退避重试；
仍然失败的记录带 `error` 字段，`tools/audit-content.py` 有一项专门拦它——
**带 error 的记录不许被当成「这篇没有来源」**。

## 内容仓的 CI 曾经不在仓里（已修）

`.gitignore` 里有一行 `.github/`——它当初是为了挡住迁往 `diuci/k12-site` 之前遗留的旧站点文件，
顺手把本仓自己的 CI 也挡在了仓外。结果：GitHub 上这个仓最后一次跑是 2026-10-03 那个旧 Pages 流程，
四十来步的护栏只活在一台机器的 `.ps1` 里，而且那份旧 workflow 还引用着早已删掉的 `check-annotations.py`。
**内容仓是所有站点的唯一事实源，它没有 CI，等于所有护栏都取决于「有人恰好记得在本地跑一遍」。**

现在 `.github/workflows/verify.yml` 入库，四步：

1. **26 项检查器自检**（每个护栏先证明它抓得住坏例子）；本轮补的第七项：`build-textbook-garden.py`（9 个坏例子：园地页抽不出篇名、栏目头被当成篇名、作者串到下一篇、篇名尾巴吃太贪）。先前几轮补的六项：`check-duplicates.py`（10 个坏例子，含《寒下曲》/《塞下曲》那一组）、
   `apply-textbook-status.py`（现在 24 个）、`apply-volume-findings.py`（13 个）——后两个会往 md 里写「统编教材收没收」
   和册次，写错就是对学生说假话，先前它们连坏例子都没有；`build.py`（27 个：正文抽取、说明小节被当正文、空正文、
   缺公有领域证据、render_split 与句数不匹配）、`inject-annotations.py`（16 个：注入不许动正文、不许跑两遍长出两节、
   空注释不许算「有内容」）、`check-textbook.py`（现在 71 个：学段判错、篇名子串乱配、对不上却没说清差在哪个字、相思≠长相思、《老子》四章≠八章、覆盖表只有一条来源）——
   这三条先前只有「跑一遍真数据」的份，坏例子一个都没有；
2. **13 项离线检查**（结构、异文、默认口径、污染、重复、截断、教材册次、作者卒年、出处、注音、正文一致性）；
3. **派生产物重算**（繁体、出处明细、台账、审计、法律护栏）；
4. **可复现闸门**：跑完 `git status --porcelain` 必须为空——提交进去的产物必须是链条跑出来的，
   不是手改出来的。这一条本轮就抓到过一次：提交进去的台账与繁体表确实和重算结果不一致。

联网的三步不在 CI 跑，写死在 workflow 的说明步里：全量出处核对、`verify-variant-claims.py --refresh`、
`check-textbook.py` 要读 `data/page-cache/` 与 `data/textbook-cache/`，这两个缓存都不入库
（统编教材是版权作品，整页镜像不许进仓）。它们只在本地链条里跑：48 步；`check-text-sources.py` 那一轮
当场报「缓存命中 709 次 / 真的联网取页 0 次」。

CI 里没有 8MB 的 `data/unihan/Unihan_Readings.txt`（已 gitignore），而「异体字表每一对必须读音相同」
那条自检需要它——存在但跑不了的检查等同于没有检查。所以改读一份入库的小快照
`data/variant-readings.json`（当场数：42 个字，由 `check-text-sources.py --export-variant-readings` 生成）。
字表加了新字而快照没重生成，`load_variant_readings()` 当场报错。本轮加「隣→邻」时它就报过一次。

### 文档里写死的数字也会过期（已加闸门）

本轮核对「里」那一节时发现：这一节写着「裁定表里有 8 条规则管着『里』」，
当场数 `data/s2t-rules.json`：102 条规则里管着「里」的只有 2 条——一条定「里巷/处所/《里仁》」照抄「里」，
一条定「哪里」作「裏」。数字本身是错的，而它长得像数过的样子：这比不写数字更容易骗人。

现在 `audit-content.py` 多了一项 `doc_number_claims`：文档里写死的「裁定表 N 条」必须与表当场数出来的条数一致，
不一致就报错。自检配了四个坏例子（17 / 17b / 17c / 17d）：过期必须报、对得上不许误伤、
文档没写数字不许报、同一份文档里两处过期不许只报一处。审计项 26 → 27 项。

本轮又把「**26 项检查器自检**」这个数字本身纳进同一项：它由 `.github/workflows/verify.yml` 里那一行行
`--selftest` 命令当场数出来（`count_ci_selftests`：说明文字里提到的 `--selftest` 不算），文档写 25 或 27 都报错（当场数是 26）。
理由很直白：「我们加了检查」这句话可以一直写在文档里，而 workflow 里那一行早就被人删了——只有数得出实数才拦得住。
自检为此多配四个坏例子（17e–17h）。
这道闸门上线当天就抓到了两处过期：文档里那句自检项数写的是 26，而 workflow 里带 `--selftest` 的命令行是 25 行
（`selftest-overlap.py` 那条不带这个旗标）；`counts_apparatus` 写 35030/2075，而 `--refresh` 之后产物当场是
两处都照产物改成了 25 项与 35029/2074。这一项现在盯十个数：裁定表条数、CI 自检项数、CI 离线检查项数
（`count_ci_block`：只数那个 `run: |` 块里的命令行，注释不算）、apparatus 的按表 / 按裁定表 / 照表原字 / 保留 / 待定、
以及出处核对的四档（全对上 / 部分对上 / 一句都对不上 / 核过没有正文页，读 `data/text-sources.json` 的 `stats`）。
自检为此再加七个坏例子（17i–17o：块里删一行必须过期、注释不许被数成一项检查、两个过期计数不许只报一个、
对得上不许误伤、出处核对的档位过期必须报）。扩到出处核对这一档也是当场抓到一处过期：文档还写着
「215 与 36」那两个档位数字，而 `--refresh` 之后产物是 214 与 37。

### `--check` 到底检查了什么（本轮补的两处）

`build.py --check` 先前只是「在内存里构建一遍不写盘」：它能抓住结构错误，抓不住「md 改过了却没重跑 build.py」。
那种情况下 `data/poems.json` 是旧的，台账、繁体表、站点、两个游戏全都读这份旧产物，而 CI 的「跑完 git status 必须为空」
照样干净——因为它重算的那些产物读的正是这份旧 poems.json。现在 `--check` 把当场构建结果与提交进去的
`data/poems.json`、`data/checksums.json` 逐字比对，不一致就停（`compare_committed`；坏例 10–10e：过期必须报、
产物不存在不许当成「没问题」、两份都过期不许只报一处）。当场验证：252 篇逐字一致，未写入。

`check-textbook.py` 的「N/M 句对上」分母先前用的是所有句子，可短于四字的句子从来没参与过比对：
一篇正文里有三字句（「鹅鹅鹅」这种）又恰好与教材逐字相同的诗，会在分母里凭空多出那几句，被长期误报成 partial。
现在分母只数真正比对过的句子，没参与的短句单独登记成 `skippedShort`。当场数：走到比对那一步的 185 条记录
（match 154 / partial 30 / mismatch 1）都带这个字段，值全是 0——这个 bug 目前一次也没坑到过：《咏鹅》在教材核对里
是 `lesson-not-found`（教材那一课没找到），它连比对都没走到。「鹅鹅鹅」是自检里的合成坏例（坏例 10），不是仓里的真数据。
口径修对了，以后坑到时不会假装它一直在盯着。

同一轮还改掉一处不可核验的说法：「本轮 751 处多候选全部落到裁定表」——751 这个数没有任何产物能重算出来，
换成 `data/traditional.json` 里当场可数的 `counts_apparatus`（按表 35065 / 按裁定表 2074 / 照表原字 8121 / 保留 92 / 待定 0）。

## 台账里记着但没写全的几处（登记，不是改过）

**1. 六篇 `recite=full`：必背名句只是全文的一个子集——现在「差在哪几句」是台账自己算的。**
`recite=full` 说要背整篇，可 `linesPunct`（必背名句）只收了其中几句。以前台账只有 `recite`
一个字段说这件事，「差在哪几句」谁也说不出来。现在 `tools/build-ledger.py` 把两样东西都切成
句子（按「。！？；」切，章句标签与引号先剥掉，只比汉字），当场算出全文里名句没盖住的句子，
写进 `data/ledger.json`（`mingjuSents` / `fullSents` / `fullGapSents` / `fullGapSample`）
和 `docs/ledger.md` 的「背诵要求写 full 的篇目：名句与全文差在哪几句」那一节。
「盖住」的口径：名句里有一句与它同形，或有一句是它的一部分（名句「学而时习之」在全文
「子曰学而时习之」里）；不足四字的短句只认同形，不许靠子串蒙过去。
算出来还是那六篇：《论语》十二章（初中）差 2 句、《论语》十二章（高中）差 7 句、
醉翁亭记 22 句、将进酒 8 句、登泰山记 29 句、蜀道难 18 句。
分站按 `recite` 玩全文（连词成句已经这样做了）；谁照 `linesPunct` 布置背诵，就会漏背——
现在漏的是哪几句写在台账里，不再只是一个字数。

**2. 四篇标着 `recite=line`，疑似口径缺陷。**
关雎（课标附录1 第 1 条）、蒹葭（第 2 条）、子衿、式微（后两篇是教材拓展、八下课外诵读）
都标 `recite=line`，台账记的背诵量是 2 句 16–17 字；这几篇的全文是 2–3 段。
问题出在课标附录1 的写法：它把篇名写作「关雎（关关雎鸠）」，括号里是**用来认这篇的首句**，不是背诵范围。
把首句当成背诵范围，整篇的背诵要求就缩成了 16 个字。
这一轮把能核的都核了：**收录**有第二条来源——统编教材镜像里四篇都在（八年级下册：
《诗经二首》关雎 21013、蒹葭 21012、式微 21014、子衿 21015，见 `data/textbook-attestations.json`，
四篇 status 都是 match）；可**背诵范围**没有第二条来源——镜像页只有课文原文与朗读音频，
没有「背诵这首诗」这类课后要求原文。所以 `recite` 仍按保守值 `line` 登记，正文与字段都不动；
谁照它布置背诵，最多只能算「至少背这两句」，不能算「背这两句就够」。

**3. 「里」在繁体里为什么不一律换成「裏」。**
裁定表 102 条（`data/s2t-rules.json`，当场数；这个数字由 `audit-content.py` 与表逐次比对，写错就报错），其中管着「里」的 2 条：里巷、处所、《里仁》篇名都作「里」，
来源页 21 处全作「里」；「裏」只用于「裡面」这类方位。所以繁体里「千里澄江似練」作「里」，
而桂枝香「征帆去棹殘陽裏」作「裏」——同一篇两个形，各按各的意思。表默认值会把「里」一律换成「裏」，那才是错的。

**4. 繁简合并的坑：征 / 徵——已裁定。**
简体「征」同时是「征」与「徵」的简化字，表的首选项是「徵」。以前注释那一遍按表换成「徵」，
正文那一遍按来源页留在「征」——同一篇里「征帆去棹」与「徵帆去棹」两种繁体形并存。
现在 `data/s2t-rules.json` 有三条裁定：默认「征」照抄（征帆、征蓬、征夫、征战、长征、出征、
从军征、东征、北征、征戍、征人；教材作「征利」「征于色」的也照教材作「征」），例外两条——
「象征」作「象徵」、「魏征」作「魏徵」。页证写在规则里：来源页《詞-桂枝香》作「征帆去棹」；
《答司馬諫議書》页内校勘注「《王臨川集》作『征』」；《孟子/告子下》作「徵于色」而教材作「征」，本篇从教材。
重新派生之后当场数：派生文件里「徵帆」0 处、「征帆」11 处；「象征」「魏征」只剩登记字段
（`ctx` / `why`）里的简体原形，繁体文本一侧全部作「象徵」「魏徵」。
`tools/build-traditional.py --selftest` 的坏例 23 就盯着这一处：两头任何一边倒回去，自检当场失败。

**5. 「鬬 / 斗」两处已经写进本篇的异文小节。**
- 过秦论「外连衡而斗诸侯」：来源页《過秦論/上》作「外連衡而鬬諸侯」，异文小节已记这一条，
  并写明鬬/斗 已进比对字表、正文与繁体都作「斗」。
- 燕歌行：来源页「孤城落日鬬兵稀」作「鬬」，同一页「寒声一夜传刁斗」仍作「斗」——
  异文小节已记下这一对，并写明不许同一篇里一半「鬬」一半「斗」。
两条都是照阿房宫赋那条已有的口径补的（「来源页作钩心鬬角（鬬、斗同）」）。

**这一节的现状**：1、4、5 已经改掉——台账多算了句子级差集，裁定表加了三条 征/徵 规则并配了坏例，
两篇的异文小节补了记录；2 仍是登记，正文与字段都不动（缺的是教材课后要求的原文页证）。

## 繁体版是怎么派生的

繁体文本里凡是留下「只有简体才用的字」的，每一处都要说得出凭什么，说不出的构建直接失败。
四档依据，按强弱排：

| 依据 | 例子 |
| --- | --- |
| 这一处的裁定记录（页证据或裁定表） | 「頭髮」「複習」 |
| 来源页写作这个形（表把它列在简体一侧） | 「𢧐」——维基文库页上就是这个字 |
| 正文自己写作这个形（单字表认为它本来就写作这个字） | 「床」在部分教材正文里就是「床」 |
| 引文：引的是别本或来源页夹注的写法，同一行带出处 | 异文一节里的「战 𢧐」 |

词组表被单字表挡下来的候选不再静默丢掉：它留在候选池里，裁定表可以选它，
但必须写理由。「两只袖子」作「兩隻」、「关系」作「關係」就是这样落档的——
单字表把「只」「系」照抄是对的（文言里「系」是拴住的意思），可现代汉语说的是两只袖子、是关系。

简体 md 正文是唯一事实源；繁体是**派生物**，不改 md。每一处「一简对多繁」都要落到某一档，
依据全部列在 `docs/traditional.md`（由 `tools/build-traditional.py` 生成）。优先级不可颠倒：

**来源页亲眼写作那个字 > `data/s2t-rules.json` 的裁定（每条必须带理由） > 繁简表的首选项**；
三样都没依据的留在待定清单，不许静默择一。

繁简表只给候选，不给结论。表是照现代繁体习惯写的，照抄会把古籍的字换掉，我们亲眼撞到的：

| 表想写成 | 应该写作 | 依据 |
|---|---|---|
| 逝者如斯**伕** | 逝者如斯**夫** | 「夫」是语气词，表把它换成了「伕」（丈夫） |
| 古之**慾**明明德 | 古之**欲**明明德 | 「慾」是后起分化字，四书作「欲」 |
| 吞二**週** | 吞二**周** | 这里是朝代，不是星期 |
| 百**裏**奚 | 百**里**奚 | 人名；来源页作「里」 |
| 五**谿** | 五**溪** | 来源页作「溪」 |
| 孔子**雲** | 孔子**云** | 「云」是「说」，不是云彩 |
| 百般红紫**鬥**芳菲 | 百般红紫**斗**芳菲 | 来源页作「斗」 |
| 山重水**復**疑无路 | 山重水**複**疑无路 | 来源页作「複」 |
| 竹之为瓦（雲） | 竹之为瓦（云） | 「云」= 说 |

### 页证据不入库，产物就必须自己记住它

来源页那一档（`page`）读的是 `data/page-cache`——这个缓存不入库（统编教材是版权作品，整页镜像不许进仓）。
CI 里没有它，先前它就去联网抓页：同一个提交在 CI 里跑出三套不同的档位数字，
同一份简体正文两次构建给出不同的繁体字——「重算结果与提交进去的产物逐字节一致」这道闸门随时会被这种抖动打红，
而它红了以后没人分得清是「产物真的变了」还是「页今天没抓到」。

现在四条规矩：

- **取页必须显式许可**（`--allow-pages`，默认关）：只有本地链条给这个旗标，CI 那一轮永远不给。抓回来的页与本地那份
  不是同一份（页改过、抓一半失败、只抓到半页都会发生），拿它当证据就是拿运气当证据。
  判据不能是「缓存目录在不在」，也不能是「缓存里有没有这一页」——两版都是这么写的，也都这么红的：
  CI 第 3 步的 26 项自检里 `check-text-sources.py --selftest`、`check-variant-sources.py --selftest` 这些会当场抓页
  并写进 `data/page-cache`，于是第 5 步的 `build-traditional.py` 看见「缓存里有这一页」就用了它——
  那一轮沿用只剩 12100 处，正文 page 9496（少 41）、注释那一档 table 35063（多 34），文档里写死的数字全过期。
  坏例 24k / 24l / 24m 盯着这一处：缓存里没有这一页不许去取；缓存里已有这一页、给了旗标不许不用；
  **没给旗标也不许用**（这一条就是那一轮 CI 红的地方，先前没有坏例子盯着它）。
- **没有页可查的那些处沿用上一份已提交产物里同一处的记录**（`apply_recorded`）：篇、字段、行、位置、问的字、
  上下文（剥过标点之后）逐字相同才沿用，差一个字符就不沿用——正文改过之后把旧证据贴到新位置上，比没有证据更危险。
  有页可查时页说话，记录永远不许盖过页；既没页也没记录时留在原档，不许凭空判成页证据。
- **注释、全文、必背名句那一档的页证据也必须存进产物**（`page_marks`）：先前只存了正文那一半，
  CI 里那一档没有记录可用、退回表，正文与「全文」两档当场对不上——《论语》十二章「全文」就是这么炸的。
- 产物里不许留下「这一轮没有页可查」这种只有这一轮才有的标记（`from_record` 只活在内存里，写文件时剥掉）：
  留下它，本地那一轮与 CI 那一轮就会生成两份不一样的产物。

自检配坏例 24 系列：同一处必须沿用；上下文不同、位置挪了一位、档位不同、记录其实是表的结论、
既没页也没记录——这五种都不许沿用；沿用不许给这一处添一个本地没有的键；产物里不许留 `from_record`；
`page_marks` 条数必须等于注释那一档当场数到的 page + variant（只存一半就是坏产物）。
本地那一轮（有页缓存）与「没有页缓存」那一轮各跑一遍 `--build`，两份 `data/traditional.json` 与
`docs/traditional.md` 逐字节相同——这一条先前是碎的，碎的那天 CI 连着红了两轮。

还有一条硬闸门：**表给的写法转不回原字的，一律拒用**（转不回就是表在换词，不是繁简）；
**表外生僻字一律不认**（表把「願」转成「𫖸」、「開」转成「𫔭」，那是扩展区残迹，不是繁体字）。

### 可逆性不一致 18 处：每一处都裁定了，登记在一张表里

繁体转回简体必须一字不差。当场数（`data/traditional.json` 的 `reversal`）：18 行、11 种字。
这 18 处没有一处是繁体写错了，全都是**反查表有损**：反查表是把 `data/opencc/STCharacters.txt` 的
「简体→繁体」反过来用的，一个繁体字对应多个简体字时它只能挑一个。先前这一档只是「列出来交代依据」，
列出来不等于裁定过——现在每一处都要在 `data/reversal-exceptions.json` 里有一条登记（11 条），
写明正文里的字、繁体写作什么、表转回成什么、为什么、凭什么。

| 正文里的字 | 繁体写作 | 反查表转回 | 裁定与凭什么 |
|---|---|---|---|
| 锺（锺子期） | 鍾 | 钟 | 保留 鍾：教材作「锺子期」，两条来源页作「鍾子期」（页内注「锺」） |
| 钟（万钟） | 鍾 | 锺 | 保留 鍾：教材作「钟」，来源页作「萬鍾」——同一个「鍾」被表挑去两头，这就是反查歧义 |
| 徵（徵于色） | 徵 | 征 | 保留 徵：正文本来就写作「徵」，仓内另有「征于色」的异文记录 |
| 於（商於之地） | 於 | 于 | 保留 於：正文本来就写作「於」 |
| 覆（反覆、重覆） | 覆 | 复 | 保留 覆：「覆」是现行简体字；表里「复」也转「覆」，反查就把「覆」认成「复」 |
| 巘 / 騑 / 纕 | 同字 | 𪩘 / 𬴂 / 𬙋 | 保留原字：反查表把这些常用繁体字转回扩展区残迹，那不是简体字 |
| 藉（藉寇兵） | 藉 | 借 | 保留 藉：教材作「藉」，仓内另有「借寇」的异文记录 |

闸门两边都拦：**没登记的不一致写不出产物**；**登记了却这一轮没用上的条目也停**（过期登记比没有登记更误导人）。
自检配坏例 25 系列（7 处）：登记表缺文件、缺依据、写「转回还是原字」的废话条目、重复登记、过期登记、
没登记的不一致，六种都要停；登记与产物严丝合缝时不许误报。审计另加一项独立核对（不靠派生工具自己说）：
产物里的 11 种不同必须与登记表 11 条完全一致，多一条少一条都报。审计项 27 → 28 项。


繁体版不只正文：注释、译文、赏析、必背名句、异文这几节（我们自己写的现代文字）同样派生、同样过闸门。
这几节没有来源页可查，依据只有裁定表和表。当场数（`data/traditional.json` 的 `counts_apparatus`）：按表 35065 处、按裁定表 2074 处、照表原字 8121 处、保留 92 处、待定 0 处。
这几节撞到的问题与正文相反——表在这里给的是**古书偏好**，不是现代繁体：

| 表想写成 | 应该写作 | 为什么 |
|---|---|---|
| **喫**粗粮 | **吃**粗粮 | 现代繁体作「吃」，「喫」是异体 |
| 頭**發**亂蓬蓬 | 頭**髮**亂蓬蓬 | 「头发」是「頭髮」；「發」是出发、发怒 |
| **復**習 | **複**習 | 复习作「複」；正文「唧唧复唧唧」仍作「復」 |
| 赞 → **贊**美 | 赞 → **讚**美 | 赞美、赞叹是称扬义；「贊」用于赞助、贊成 |
| 树**廕** | 树**蔭** | 「廕」是庇荫、官荫的古义 |
| 一**箇** | 一**個** | 「箇」是古体 |

反过来，正文里来源页写作「牀」的（静夜思页作「牀前看月光」），我们照页写作「牀」，
同一篇的注释译文也跟着写「牀」——同一页不许出现同一个词两种字形。

### 教材篇名匹配只认一个方向的包含（本轮改）

先前 `tools/check-textbook.py` 的 `match_lesson` 把包含关系两头都认：只要一方是另一方的一部分，就算同一篇。
它把两对判成了「我们册次写错了」：

- 忆江南（白居易，三年级下册）↔ 同一册目录里的「2 江南」（汉乐府）
- 舟夜书所见（查慎行，二年级下册）↔ 三年级下册的「夜书所见」（叶绍翁）

两对的共同点是**教材篇名只是仓内篇名的一部分**。现在只认「教材名比仓内名长」这一个方向
（仓内名少于三字的除外——「春」配到「春风」就是把两篇课文合成一篇）：教材那边常用「词牌·题目」
或「篇名（说明）」，《天净沙·秋思》对仓内《天净沙》+副标题「秋思」、《相见欢（金陵城上西楼）》对《相见欢》、
《离骚（节选）》《归去来兮辞并序》同理。镜像在课文名后面挂的作者（「天上的街市 V 郭沫若」）先剥掉。

同名不等于同篇。册次对不上时先拿正文比（`cross_volume_status`）：比得上才是「同一篇、册次要改」；
正文取到了、本来有可比的句子却一句都没对上，那是另一篇；正文取不到、或可比的句子一句都没有，
**不许下结论**，note 里写明「没核」。原来 6 条 volume-mismatch 现在的样子（当场数 `data/textbook-attestations.json`：volume-mismatch 0 条）：

| 篇 | 结论 |
|---|---|
| 相见欢（李煜，九上） | 教材八上有「相见欢（金陵城上西楼）」（朱敦儒），正文 8 句一句都没对上 → 那是另一篇 |
| 凉州词（王之涣，五下） | 教材四上有「凉州词」（王翰），正文 2 句一句都没对上 → 那是另一篇 |
| 《吕氏春秋》一则（伯牙鼓琴） | 覆盖表交代：教材六上第 22 课《伯牙鼓琴》 |
| 《礼记》一则（虽有嘉肴） | 覆盖表交代：教材八下第 22 课《〈礼记〉二则》里的《虽有嘉肴》（课标 + 目录 + 练习卷三条来源） |
| 忆江南（白居易，三下） | 课文目录没有这一课，同一册的语文园地页有；园地页与目录页同源（同一镜像），只算一条来源 → 不判成教材收了 |
| 舟夜书所见（查慎行，二下） | 同上 |

核对表（`data/textbook-attestations.json`，252 行）以前只是生成出来给人看，没接进校验：
它说没收、篇目文件说收了，站点照篇目文件显示，学生照着背错。现在 `tools/validate.py` 逐篇比对两边，
映射写在 `attest_expect` 里，两条容易混的分开对待：`mismatch` 在**同一册**里找到那一课是「收了、正文有出入」，
在**别的册**里找到同名课文才是「同名另一篇」（靠 `declaredVolume` 分）；园地证据只有一条来源，不改变收录结论。
自检配 10 个坏例子（核对表说收了篇内写没收、覆盖表收了却写「收录」、核对表缺这一篇、跨册同名写成收录、
册次对不上没交代、没见过的结论、五档标签与 `apply-textbook-status.py` 分叉，都要报；同一册正文出入与
园地证据加同名另一篇不许误报）。把 `check_attestation_status` 改成永远不报，自检当场失败（6 处坏例子全冒出来）。
接进来当场揪出 2 处不一致，都改了：《礼记》一则补上「收在别的课里」与收录范围一节；梅花按同名另一篇保留。

还揪出一条**新开的口子**：《离骚》先前靠覆盖表才找到那一课，篇名规则修好后它在自己那册直接对上
「1.2 离骚（节选）」，可比对的 30 句只有 2 句对上——教材那一课是节选，仓内是全篇，这 2/30 到底差在哪，
还没查。它现在记作 partial，不记作「教材没收」，也不许拿节选正文去改仓内全文。

## 被我们删掉的工具

- `tools/build-char-variants.py` + `data/char-variants.json`：想用 Unihan 的异体字段自动建异体表，
  自检跑不过 —— 异体关系按 `kSemanticVariant` 合并会抹平 說/悅、知/智 这类真异文，工具已删。
- `tools/check-annotations.py`：早期粗筛脚本，三项检查全是假阳性 ——
  把注音拼音（`丁，读 zhēng`、`謇，jiǎn`）当成「英文残留」15 处；
  「注释词每个字都必须在诗里」正是我们已经否决的粗口径（见下）；译文按字数比例判长短。
  它不在构建链条里、也没有别处引用，留在仓里只会让下一次体检报告长出 200 多条假问题，故删。
