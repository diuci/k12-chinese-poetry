# 内容准确性与免责（内容仓侧）

这一页写的是**我们核对到了哪一步**，不是「我们保证没错」。
站点上那一页（`/accuracy`）由 `k12-site/tools/build-site.py` 从台账当场生成，数字不会写死过期；
这一页写的是口径与方法，数字以 `data/ledger.json` 与 `docs/audit.md` 为准。

## 我们对外承诺的口径

1. **收哪些篇**只认课标；**哪一册第几课、教材用哪个字**只认人教社公开页面；
   **古籍原文与异文**认维基文库与中国哲学书电子化计划。
2. **教材版为准 + 附异文清单**，不静默择一。改正文之前必须有第二条独立来源；
   只有镜像证据的改动只登记、不改正文。
3. **没核到就写没核到。** 缺出处的异文条目一律写明「出处：仓内没核到」。
   把「没核到」写成「有出处」等于编造，这一条没有例外。
4. **注释、译文、赏析是我们自己写的**（cc-by-4.0），不是教材里的，也不是教研结论。
   引用本篇原文必须一字不差——引错原文比缺出处更严重，因为那是拿一句不存在的话教给学生。
5. 原文只收**作者卒年 + 50 年已届满**的；这条是 `tools/validate.py` 在跑的规则，不是文档里的说法。

## 核对是怎么做的

- 把仓内每一篇的**句子**（不是整段）剥掉标点，拿去来源页里逐句找；
- 来源页繁体先过一遍繁简转换表再比（不转会造出假「对不上」）；
- 来源页的「一作某」夹注从正文里剥出来，单独登记成异文；
- **搜到一句话不等于找到了来源**：来源页必须装得下这篇正文才算；
- 页坏（生僻字残迹、脚注数字残迹、版权提示插在正文中间）**往往只是渲染坏了**，
  wikitext 可能干净——先怀疑页，不急着改正文。

### 核对单位曾经错过一次（已修）

`tools/check-text-sources.py` 以前只核 `lines`。对长诗与散文，`lines` 就是必背名句：
离骚核的是 4 句、答司马谏议书核的是 6 句，而仓里真正发出去的正文另有 26 联、4 段——
**那部分从没进过这道核对**，台账上「逐句全对上」因此是半真半假的。

现在改成：`lines` 与 `fullLines` 合并，并按句末点号切成句子再比。
散文的 `fullLines` 是整段（答司马谏议书 4 段、每段上百字），整段比对差一个字就整段不算对上，
所以必须切到句子。改完之后核对的句子数从约 900 句涨到约 1,900 句，
**全对上的篇数下降是预期的**——那是把原来没查的部分查了。

### 比对里曾经有一档「像就算对上」（已撤）

`line_in()` 原先退到最后一档：`difflib` 相似度 ≥ 0.82 就返回 `near`，算「对上了」。这一档已撤。
撤它的理由不是「它已经骗过了谁」，是**它能凭空造出命中**：只差一个字的两行相似度 0.9，

这句话是数出来的，不是推断。撤除那一轮记的是 215 与 36；当场数当前产物（`data/text-sources.json` 的 `stats`）：

1. **锚点是句子的第一个字符。** 仓里有些正文以 ASCII 引号开头（"传其事以为官戒也），页里没有引号字符，

   找不到才退回网格扫。

被救回来的三句都是当场从真页里发现的：种树郭橐驼传「传其事以为官戒也」（页里作「传其事以为官戒」）、

**这一轮又清了一遍「来源页作「某」」里的假话。** 比对的页文本是繁→简转换过的，而 OpenCC 字表里有
**997 条歧义条目**——一个繁体字给两个候选（`藉→藉 借`、`覆→覆 复`、`於→于 於`、`餘→余 馀`、`讎→仇雠`）。
比对时两个候选都认是对的（宁可宽），可同一份文本又被拿去写「页里最像的一段」和篇内的异文条目，
于是两个候选被拼在一起写给了读者：「来源页作「藉借寇兵」」「若重覆复之」「商于於之地」「终余馀年」「征徵于色」——

`data/reversal-exceptions.json` 里的依据也跟着改了（还有一条把「萬鍾」记到《告子下》，实际在《告子上》）。

修的是工具，不只是句子。`check-text-sources.py` 现在有三份页文本，各管各的：`clean()` 比对用
（两个候选都认）；`clean_quote()` 引用用（歧义字照抄页里那个字，也不许把页里的字换成扩展区残迹——
表里「巘→𪩘」这种单值条目照转会造出一个页里根本没有的字）；`strip_only()` 一个字都不换，
用来问「页里到底写了哪些字」。「页里最像的一段」改用 `clean_quote()`；`nearest` 的锚点从「句子的第一个字」
放宽到「前三个字各试一遍」（我们作「哪里」、页作「那里」，只锚第一个字就会把一句明明写作别的样子判成「页里没找到」）。

（30 篇 39 句：A 0、B 38、C 1）——这一轮改的是「页里写了什么」怎么说，不是把谁算成对上。

**这一轮把「页里到底有没有」这件事重做了一遍。** 37 篇「部分对上」里有 6 篇整篇的句子都对不上，逐条查下去，
抓出来的全是工具自己的毛病，不是内容的毛病：

1. **页里的注码是 HTML 数字实体**（`&#91;13&#93;` 就是注码 [13]）。先前只剥字母实体、不剥数字实体，
   而下一步又把 `#` 当标点剥掉，剩下「&91;13&93;」卡在正文里把句子打断——谏逐客书两句在页里明写着，
   却被判成没找到。坏例 10。
2. **仓里有些正文用 ASCII 引号**（《孟子》一则「"敢问夫子恶乎长"」）。head/tail 取到引号本身，
   页里明写着的句子就被判成没对上。坏例 11。
3. **切句留下的纯标点碎片**（剥完标点什么都不剩的「'"」）先前被当成「没对上的句子」记进台账——
   那是切句切出来的，不是内容缺陷。现在 `blank_fragments()` 当场报数、从核对里剔掉。坏例 12–12c。
4. **同一个 tail 在页里出现两次时，先前取全文最后一个**：曹刿论战那一页「弗从也」出现两处，
   取远处那个，窗口被拉到别处，紧挨着的那一段反倒不算对上。改成逐个 head 往后看、窗口按句长封顶。坏例 13–13b。
5. **`nearest` 用带标点的原文去比去标点的页**：同一句带不带引号，相似度从 0.70 掉到 0.61，
   页里明写着的那一段被压到阈值以下。现在两边都先剥标点。坏例 14。
6. **维基文库的页面家具不是正文**：页尾那段「此唐朝作品在全世界都属于公有领域…」、页头的「姊妹计划:数据项」、
   小节之间的「编辑」链接、Wikidata 的 true/false。留着它们，种树郭橐驼传「传其事以为官戒也」的相似度
   被页尾声明压到 0.538（阈值 0.55），从「页里写作别的样子」掉进「页里没找到」。坏例 15–15d。
   剥法本身差点吃掉正文：那条正则先前把「此」写成可选，从左边贪吃，把「…传其事以为官戒」里的「官戒」吃了进去——
   护栏吃掉正文比不剥更糟，坏例 15 当场把它抓住。
7. **我们自己加的小节标签不许算进句子**：古代文论选段六句 C 档里五句是这么来的——
   「【毛诗序】诗者，志之所之也」整句去比，来源页明写着后半句，前面却没有「毛诗序」三个字。坏例 16–16c。

## 同一个字的另一种写法：认，但不许瞎认

来源页写作「未甞」「山隂」「修脩稧」「靑」「髙」「衞」，我们写作「未尝」「山阴」「修禊」「青」「高」「卫」。
不认这些写法，工具就把「页里明写着这一句」报成「我们对不上」——那是工具的脆，不是内容的错。

所以比对时认一批「同一个字的另一种写法」（`check-text-sources.py` 的 `VARIANT_GLYPHS`）。
每一对都必须在来源页上亲眼看到，并且过一道自检：**两边的 Unihan `kMandarin` 读音必须有交集**。

这道自检当场拦下了我自己加的一对：`彊` 在 Unihan 里读 jiàng、`强` 读 qiáng，
不能断定是同一个字，所以谏逐客书那一句留在「没对上」里，作为异文登记。
同样被明确排除的还有义近字与真异文：說/悅、知/智、蔽/敝、渡/度、歧/岐、欤/与、那/哪、己/已——
**把真异文抹平成「同一个字」，比查不出来更糟**，因为那会让读者以为已经核过了。

试过现成的异体字表（Unicode Unihan），结论是这条路给不出我们要的对子，已放弃：
异体关系写在 `Unihan_Variants.txt` 的 `kSemanticVariant` 等字段里，而 `kSemanticVariant` 正是必须排除的那一类——
按它合并会把 說/悅、知/智 一起抹平；`甞` 的 `kSemanticVariant` 指向的是另一个字（U+83D1），不是 `嘗`。
所以这张表只能自己建、自己一条条在页上验，工具 `build-char-variants.py` 连同它的产物已从仓里删掉：
**跑不过自己自检的工具留在仓里，比没有工具更危险。**

## 网络失败不是内容问题

维基文库被连着问几百次会直接拒连接（WinError 10061）。以前一次失败就记「找不到来源页」，
台账上凭空多出 20 篇「没有来源」。现在 `http_json()` 退避重试；
仍然失败的记录带 `error` 字段，`tools/audit-content.py` 有一项专门拦它——
**带 error 的记录不许被当成「这篇没有来源」**。

### 文档里写死的数字也会过期（已加闸门）

本轮核对「里」那一节时发现：这一节写着「裁定表里有 8 条规则管着『里』」，
当场数 `data/s2t-rules.json`：102 条规则里管着「里」的只有 2 条——一条定「里巷/处所/《里仁》」照抄「里」，
一条定「哪里」作「裏」。数字本身是错的，而它长得像数过的样子：这比不写数字更容易骗人。

现在 `audit-content.py` 多了一项 `doc_number_claims`：文档里写死的「裁定表 N 条」必须与表当场数出来的条数一致，
不一致就报错。自检配了四个坏例子（17 / 17b / 17c / 17d）：过期必须报、对得上不许误伤、
文档没写数字不许报、同一份文档里两处过期不许只报一处。审计项从这一轮起又加了一项（当场数见 `docs/audit.md`）。

本轮又把「**30 项检查器自检**」这个数字本身纳进同一项：它由 `.github/workflows/verify.yml` 里那一行行
`--selftest` 命令当场数出来（`count_ci_selftests`：说明文字里提到的 `--selftest` 不算），文档写 25 或 27 都报错（当场数是 26）。
理由很直白：「我们加了检查」这句话可以一直写在文档里，而 workflow 里那一行早就被人删了——只有数得出实数才拦得住。
自检为此多配四个坏例子（17e–17h）。
这道闸门上线当天就抓到了两处过期：文档里那句自检项数写的是 26，而 workflow 里带 `--selftest` 的命令行是 25 行
（`selftest-overlap.py` 那条不带这个旗标）；`counts_apparatus` 写 35030/2075，而 `--refresh` 之后产物当场是
两处都照产物改成了 25 项与 35029/2074。这一项现在盯十个数：裁定表条数、CI 自检项数、CI 离线检查项数
（`count_ci_block`：只数那个 `run: |` 块里的命令行，注释不算）、apparatus 的按表 / 按裁定表 / 照表原字 / 保留 / 待定、
以及出处核对的四档（全对上 / 部分对上 / 一句都对不上 / 核过没有正文页，读 `data/text-sources.json` 的 `stats`）。
自检为此再加七个坏例子（17i–17o：块里删一行必须过期、注释不许被数成一项检查、两个过期计数不许只报一个、
对得上不许误伤、出处核对的档位过期必须报）。扩到出处核对这一档也是当场抓到一处过期：文档还写着
「215 与 36」那两个档位数字，而 `--refresh` 之后产物是 214 与 37。

### `--check` 到底检查了什么（本轮补的两处）

`build.py --check` 先前只是「在内存里构建一遍不写盘」：它能抓住结构错误，抓不住「md 改过了却没重跑 build.py」。
那种情况下 `data/poems.json` 是旧的，台账、繁体表、站点、两个游戏全都读这份旧产物，而 CI 的「跑完 git status 必须为空」
照样干净——因为它重算的那些产物读的正是这份旧 poems.json。现在 `--check` 把当场构建结果与提交进去的
`data/poems.json`、`data/checksums.json` 逐字比对，不一致就停（`compare_committed`；坏例 10–10e：过期必须报、
产物不存在不许当成「没问题」、两份都过期不许只报一处）。当场验证：252 篇逐字一致，未写入。

`check-textbook.py` 的「N/M 句对上」分母先前用的是所有句子，可短于四字的句子从来没参与过比对：
一篇正文里有三字句（「鹅鹅鹅」这种）又恰好与教材逐字相同的诗，会在分母里凭空多出那几句，被长期误报成 partial。
现在分母只数真正比对过的句子，没参与的短句单独登记成 `skippedShort`。当场数：走到比对那一步的 185 条记录
（match / partial / mismatch 三档的当场数见 `data/textbook-attestations.json`）都带这个字段，值全是 0——这个 bug 目前一次也没坑到过：《咏鹅》在教材核对里
是 `lesson-not-found`（教材那一课没找到），它连比对都没走到。「鹅鹅鹅」是自检里的合成坏例（坏例 10），不是仓里的真数据。
口径修对了，以后坑到时不会假装它一直在盯着。

同一轮还改掉一处不可核验的说法：「本轮 751 处多候选全部落到裁定表」——751 这个数没有任何产物能重算出来，
换成 `data/traditional.json` 里当场可数的 `counts_apparatus`（按表 41293 / 按裁定表 2232 / 照表原字 9284 / 保留 80 / 待定 0）。

## 台账里记着但没写全的几处（登记，不是改过）

**1. 六篇 `recite=full`：必背名句只是全文的一个子集——现在「差在哪几句」是台账自己算的。**
`recite=full` 说要背整篇，可 `linesPunct`（必背名句）只收了其中几句。以前台账只有 `recite`
一个字段说这件事，「差在哪几句」谁也说不出来。现在 `tools/build-ledger.py` 把两样东西都切成
句子（按「。！？；」切，章句标签与引号先剥掉，只比汉字），当场算出全文里名句没盖住的句子，
写进 `data/ledger.json`（`mingjuSents` / `fullSents` / `fullGapSents` / `fullGapSample`）
和 `docs/ledger.md` 的「背诵要求写 full 的篇目：名句与全文差在哪几句」那一节。
「盖住」的口径：名句里有一句与它同形，或有一句是它的一部分（名句「学而时习之」在全文
「子曰学而时习之」里）；不足四字的短句只认同形，不许靠子串蒙过去。
算出来还是那六篇：《论语》十二章（初中）差 2 句、《论语》十二章（高中）差 7 句、
醉翁亭记 22 句、将进酒 8 句、登泰山记 29 句、蜀道难 18 句。
分站按 `recite` 玩全文（连词成句已经这样做了）；谁照 `linesPunct` 布置背诵，就会漏背——
现在漏的是哪几句写在台账里，不再只是一个字数。

**2. 四篇标着 `recite=line`，疑似口径缺陷。**
关雎（课标附录1 第 1 条）、蒹葭（第 2 条）、子衿、式微（后两篇是教材拓展、八下课外诵读）
都标 `recite=line`，台账记的背诵量是 2 句 16–17 字；这几篇的全文是 2–3 段。
问题出在课标附录1 的写法：它把篇名写作「关雎（关关雎鸠）」，括号里是**用来认这篇的首句**，不是背诵范围。
把首句当成背诵范围，整篇的背诵要求就缩成了 16 个字。
这一轮把能核的都核了：**收录**有第二条来源——统编教材镜像里四篇都在（八年级下册：
《诗经二首》关雎 21013、蒹葭 21012、式微 21014、子衿 21015，见 `data/textbook-attestations.json`，
四篇 status 都是 match）；可**背诵范围**没有第二条来源——镜像页只有课文原文与朗读音频，
没有「背诵这首诗」这类课后要求原文。所以 `recite` 仍按保守值 `line` 登记，正文与字段都不动；
谁照它布置背诵，最多只能算「至少背这两句」，不能算「背这两句就够」。

**3. 「里」在繁体里为什么不一律换成「裏」。**
裁定表 102 条（`data/s2t-rules.json`，当场数；这个数字由 `audit-content.py` 与表逐次比对，写错就报错），其中管着「里」的 2 条：里巷、处所、《里仁》篇名都作「里」，
来源页 21 处全作「里」；「裏」只用于「裡面」这类方位。所以繁体里「千里澄江似練」作「里」，
而桂枝香「征帆去棹殘陽裏」作「裏」——同一篇两个形，各按各的意思。表默认值会把「里」一律换成「裏」，那才是错的。

**4. 繁简合并的坑：征 / 徵——已裁定。**
简体「征」同时是「征」与「徵」的简化字，表的首选项是「徵」。以前注释那一遍按表换成「徵」，
正文那一遍按来源页留在「征」——同一篇里「征帆去棹」与「徵帆去棹」两种繁体形并存。
现在 `data/s2t-rules.json` 有三条裁定：默认「征」照抄（征帆、征蓬、征夫、征战、长征、出征、
从军征、东征、北征、征戍、征人；教材作「征利」「征于色」的也照教材作「征」），例外两条——
「象征」作「象徵」、「魏征」作「魏徵」。页证写在规则里：来源页《詞-桂枝香》作「征帆去棹」；
《答司馬諫議書》页内校勘注「《王臨川集》作『征』」；《孟子/告子下》作「徵于色」而教材作「征」，本篇从教材。

## 繁体版是怎么派生的

繁体文本里凡是留下「只有简体才用的字」的，每一处都要说得出凭什么，说不出的构建直接失败。
四档依据，按强弱排：

| 依据 | 例子 |
| --- | --- |
| 这一处的裁定记录（页证据或裁定表） | 「頭髮」「複習」 |
| 来源页写作这个形（表把它列在简体一侧） | 「𢧐」——维基文库页上就是这个字 |
| 正文自己写作这个形（单字表认为它本来就写作这个字） | 「床」在部分教材正文里就是「床」 |
| 引文：引的是别本或来源页夹注的写法，同一行带出处 | 异文一节里的「战 𢧐」 |

词组表被单字表挡下来的候选不再静默丢掉：它留在候选池里，裁定表可以选它，
但必须写理由。「两只袖子」作「兩隻」、「关系」作「關係」就是这样落档的——
单字表把「只」「系」照抄是对的（文言里「系」是拴住的意思），可现代汉语说的是两只袖子、是关系。

简体 md 正文是唯一事实源；繁体是**派生物**，不改 md。每一处「一简对多繁」都要落到某一档，
依据全部列在 `docs/traditional.md`（由 `tools/build-traditional.py` 生成）。优先级不可颠倒：

**来源页亲眼写作那个字 > `data/s2t-rules.json` 的裁定（每条必须带理由） > 繁简表的首选项**；
三样都没依据的留在待定清单，不许静默择一。

繁简表只给候选，不给结论。表是照现代繁体习惯写的，照抄会把古籍的字换掉，我们亲眼撞到的：

| 表想写成 | 应该写作 | 依据 |
|---|---|---|
| 逝者如斯**伕** | 逝者如斯**夫** | 「夫」是语气词，表把它换成了「伕」（丈夫） |
| 古之**慾**明明德 | 古之**欲**明明德 | 「慾」是后起分化字，四书作「欲」 |
| 吞二**週** | 吞二**周** | 这里是朝代，不是星期 |
| 百**裏**奚 | 百**里**奚 | 人名；来源页作「里」 |
| 五**谿** | 五**溪** | 来源页作「溪」 |
| 孔子**雲** | 孔子**云** | 「云」是「说」，不是云彩 |
| 百般红紫**鬥**芳菲 | 百般红紫**斗**芳菲 | 来源页作「斗」 |
| 山重水**復**疑无路 | 山重水**複**疑无路 | 来源页作「複」 |
| 竹之为瓦（雲） | 竹之为瓦（云） | 「云」= 说 |

### 页证据不入库，产物就必须自己记住它

来源页那一档（`page`）读的是 `data/page-cache`——这个缓存不入库（统编教材是版权作品，整页镜像不许进仓）。
CI 里没有它，先前它就去联网抓页：同一个提交在 CI 里跑出三套不同的档位数字，
同一份简体正文两次构建给出不同的繁体字——「重算结果与提交进去的产物逐字节一致」这道闸门随时会被这种抖动打红，
而它红了以后没人分得清是「产物真的变了」还是「页今天没抓到」。

现在四条规矩：

- **取页必须显式许可**（`--allow-pages`，默认关）：只有本地链条给这个旗标，CI 那一轮永远不给。抓回来的页与本地那份
  不是同一份（页改过、抓一半失败、只抓到半页都会发生），拿它当证据就是拿运气当证据。
  判据不能是「缓存目录在不在」，也不能是「缓存里有没有这一页」——两版都是这么写的，也都这么红的：
  CI 第 3 步的 28 项自检里 `check-text-sources.py --selftest`、`check-variant-sources.py --selftest` 这些会当场抓页
  并写进 `data/page-cache`，于是第 5 步的 `build-traditional.py` 看见「缓存里有这一页」就用了它——
  那一轮沿用只剩 12100 处，正文 page 9496（少 41）、注释那一档 table 35063（多 34），文档里写死的数字全过期。
  坏例 24k / 24l / 24m 盯着这一处：缓存里没有这一页不许去取；缓存里已有这一页、给了旗标不许不用；
  **没给旗标也不许用**（这一条就是那一轮 CI 红的地方，先前没有坏例子盯着它）。
- **没有页可查的那些处沿用上一份已提交产物里同一处的记录**（`apply_recorded`）：篇、字段、行、位置、问的字、
  上下文（剥过标点之后）逐字相同才沿用，差一个字符就不沿用——正文改过之后把旧证据贴到新位置上，比没有证据更危险。
  有页可查时页说话，记录永远不许盖过页；既没页也没记录时留在原档，不许凭空判成页证据。
- **注释、全文、必背名句那一档的页证据也必须存进产物**（`page_marks`）：先前只存了正文那一半，
  CI 里那一档没有记录可用、退回表，正文与「全文」两档当场对不上——《论语》十二章「全文」就是这么炸的。
- 产物里不许留下「这一轮没有页可查」这种只有这一轮才有的标记（`from_record` 只活在内存里，写文件时剥掉）：
  留下它，本地那一轮与 CI 那一轮就会生成两份不一样的产物。

自检配坏例 24 系列：同一处必须沿用；上下文不同、位置挪了一位、档位不同、记录其实是表的结论、
既没页也没记录——这五种都不许沿用；沿用不许给这一处添一个本地没有的键；产物里不许留 `from_record`；
`page_marks` 条数必须等于注释那一档当场数到的 page + variant（只存一半就是坏产物）。
本地那一轮（有页缓存）与「没有页缓存」那一轮各跑一遍 `--build`，两份 `data/traditional.json` 与
`docs/traditional.md` 逐字节相同——这一条先前是碎的，碎的那天 CI 连着红了两轮。

还有一条硬闸门：**表给的写法转不回原字的，一律拒用**（转不回就是表在换词，不是繁简）；
**表外生僻字一律不认**（表把「願」转成「𫖸」、「開」转成「𫔭」，那是扩展区残迹，不是繁体字）。

### 可逆性不一致 18 处：每一处都裁定了，登记在一张表里

繁体转回简体必须一字不差。当场数（`data/traditional.json` 的 `reversal`）：18 行、11 种字。
这 18 处没有一处是繁体写错了，全都是**反查表有损**：反查表是把 `data/opencc/STCharacters.txt` 的
「简体→繁体」反过来用的，一个繁体字对应多个简体字时它只能挑一个。先前这一档只是「列出来交代依据」，
列出来不等于裁定过——现在每一处都要在 `data/reversal-exceptions.json` 里有一条登记（11 条），
写明正文里的字、繁体写作什么、表转回成什么、为什么、凭什么。

| 正文里的字 | 繁体写作 | 反查表转回 | 裁定与凭什么 |
|---|---|---|---|
| 锺（锺子期） | 鍾 | 钟 | 保留 鍾：教材作「锺子期」，两条来源页作「鍾子期」（页内注「锺」） |
| 钟（万钟） | 鍾 | 锺 | 保留 鍾：教材作「钟」，来源页作「萬鍾」——同一个「鍾」被表挑去两头，这就是反查歧义 |
| 徵（徵于色） | 徵 | 征 | 保留 徵：正文本来就写作「徵」，仓内另有「征于色」的异文记录 |
| 於（商於之地） | 於 | 于 | 保留 於：正文本来就写作「於」 |
| 覆（反覆、重覆） | 覆 | 复 | 保留 覆：「覆」是现行简体字；表里「复」也转「覆」，反查就把「覆」认成「复」 |
| 巘 / 騑 / 纕 | 同字 | 𪩘 / 𬴂 / 𬙋 | 保留原字：反查表把这些常用繁体字转回扩展区残迹，那不是简体字 |
| 藉（藉寇兵） | 藉 | 借 | 保留 藉：教材作「藉」，仓内另有「借寇」的异文记录 |

闸门两边都拦：**没登记的不一致写不出产物**；**登记了却这一轮没用上的条目也停**（过期登记比没有登记更误导人）。
自检配坏例 25 系列（7 处）：登记表缺文件、缺依据、写「转回还是原字」的废话条目、重复登记、过期登记、
没登记的不一致，六种都要停；登记与产物严丝合缝时不许误报。审计另加一项独立核对（不靠派生工具自己说）：
产物里的 11 种不同必须与登记表 11 条完全一致，多一条少一条都报。审计项 27 → 28 项。


繁体版不只正文：注释、译文、赏析、必背名句、异文这几节（我们自己写的现代文字）同样派生、同样过闸门。
这几节没有来源页可查，依据只有裁定表和表。当场数（`data/traditional.json` 的 `counts_apparatus`）：按表 41293 处、按裁定表 2232 处、照表原字 9284 处、保留 80 处、待定 0 处。
比上一轮多出来的 96 / 5 / 19 处，是《相思》新加的「收录范围」一节进了派生表——那一节写的是查过什么，不是正文。
这几节撞到的问题与正文相反——表在这里给的是**古书偏好**，不是现代繁体：

| 表想写成 | 应该写作 | 为什么 |
|---|---|---|
| **喫**粗粮 | **吃**粗粮 | 现代繁体作「吃」，「喫」是异体 |
| 頭**發**亂蓬蓬 | 頭**髮**亂蓬蓬 | 「头发」是「頭髮」；「發」是出发、发怒 |
| **復**習 | **複**習 | 复习作「複」；正文「唧唧复唧唧」仍作「復」 |
| 赞 → **贊**美 | 赞 → **讚**美 | 赞美、赞叹是称扬义；「贊」用于赞助、贊成 |
| 树**廕** | 树**蔭** | 「廕」是庇荫、官荫的古义 |
| 一**箇** | 一**個** | 「箇」是古体 |

反过来，正文里来源页写作「牀」的（静夜思页作「牀前看月光」），我们照页写作「牀」，
同一篇的注释译文也跟着写「牀」——同一页不许出现同一个词两种字形。

### 教材篇名匹配只认一个方向的包含（本轮改）

先前 `tools/check-textbook.py` 的 `match_lesson` 把包含关系两头都认：只要一方是另一方的一部分，就算同一篇。
它把两对判成了「我们册次写错了」：

- 忆江南（白居易，三年级下册）↔ 同一册目录里的「2 江南」（汉乐府）
- 舟夜书所见（查慎行，二年级下册）↔ 三年级下册的「夜书所见」（叶绍翁）

两对的共同点是**教材篇名只是仓内篇名的一部分**。现在只认「教材名比仓内名长」这一个方向
（仓内名少于三字的除外——「春」配到「春风」就是把两篇课文合成一篇）：教材那边常用「词牌·题目」
或「篇名（说明）」，《天净沙·秋思》对仓内《天净沙》+副标题「秋思」、《相见欢（金陵城上西楼）》对《相见欢》、
《离骚（节选）》《归去来兮辞并序》同理。镜像在课文名后面挂的作者（「天上的街市 V 郭沫若」）先剥掉。

同名不等于同篇。册次对不上时先拿正文比（`cross_volume_status`）：比得上才是「同一篇、册次要改」；
正文取到了、本来有可比的句子却一句都没对上，那是另一篇；正文取不到、或可比的句子一句都没有，
**不许下结论**，note 里写明「没核」。原来 6 条 volume-mismatch 现在的样子（当场数 `data/textbook-attestations.json`：volume-mismatch 0 条）：

| 篇 | 结论 |
|---|---|
| 相见欢（李煜，九上） | 教材八上有「相见欢（金陵城上西楼）」（朱敦儒），正文 8 句一句都没对上 → 那是另一篇 |
| 凉州词（王之涣，五下） | 教材四上有「凉州词」（王翰），正文 2 句一句都没对上 → 那是另一篇 |
| 《吕氏春秋》一则（伯牙鼓琴） | 覆盖表交代：教材六上第 22 课《伯牙鼓琴》 |
| 《礼记》一则（虽有嘉肴） | 覆盖表交代：教材八下第 22 课《〈礼记〉二则》里的《虽有嘉肴》（课标 + 目录 + 练习卷三条来源） |
| 忆江南（白居易，三下） | 课文目录没有这一课，同一册的语文园地页有；园地页与目录页同源（同一镜像），只算一条来源 → 不判成教材收了 |
| 舟夜书所见（查慎行，二下） | 同上 |

核对表（`data/textbook-attestations.json`，252 行）以前只是生成出来给人看，没接进校验：
它说没收、篇目文件说收了，站点照篇目文件显示，学生照着背错。现在 `tools/validate.py` 逐篇比对两边，
映射写在 `attest_expect` 里，两条容易混的分开对待：`mismatch` 在**同一册**里找到那一课是「收了、正文有出入」，
在**别的册**里找到同名课文才是「同名另一篇」（靠 `declaredVolume` 分）；园地证据只有一条来源，不改变收录结论。
自检配 19 个坏例子（核对表说收了篇内写没收、覆盖表收了却写「收录」、核对表缺这一篇、跨册同名写成收录、
册次对不上没交代、没见过的结论、七档标签与 `apply-textbook-status.py` 分叉，都要报；同一册正文出入与
园地证据加同名另一篇不许误报）。把 `check_attestation_status` 改成永远不报，自检当场失败（6 处坏例子全冒出来）。
接进来当场揪出 2 处不一致，都改了：《礼记》一则补上「收在别的课里」与收录范围一节；梅花当时按「同名另一篇」保留，
本轮查明那条同名是前缀匹配造出来的（教材里那一篇叫《梅花魂》），已撤。

还揪出一条**新开的口子**：《离骚》先前靠覆盖表才找到那一课，篇名规则修好后它在自己那册直接对上「1.2 离骚（节选）」，可比对的 30 句只有 2 句对上。
本轮查到底了，结论是**先前写在仓里的那条「教材选的是哪一段」是错的**：《离骚》篇里写着统编那一课收的是「长太息以掩涕兮」到「岂余心之可惩」（26 联），
可统编课文页（镜像）给的那一段是「帝高阳之苗裔兮」到「来吾道夫先路」（12 联），菁优网那份「选择性必修下册 1.2 离骚」同步练习卷也从「帝高阳之苗裔兮」出题。
先前那三条来源说的是**高考必背那一段**（旧人教必修 2 的节选也是它），不是统编这一课。这一篇的正文因此补上了开头 12 联（共 38 联），
统编这一课的**止点**两条来源不一致，仓内记作没定论，页上写明哪一段有教材页撑着、哪一段只有高考必背撑着。句子仍逐联取自公有领域的维基文库《離騷》。

## 这一轮：三篇正文自己漏了东西，护栏补上一条

**先说结论**：教材比对里那 32 篇「部分对上」，本轮先挑最像有事的三篇逐条查，结果三篇都有真问题，不是比对方法的错。

1. **《出师表》正文照的是《文选》／《诸葛亮集》，不是统编教材本**，而且**缺了一整段**——旧正文到「受命以」就断了，「受命以来，夙夜忧叹……此臣所以报先帝而忠陛下之职分也。至于斟酌损益，进尽忠言，则攸之、祎、允之任也。」全仓搜不到（当场搜「夙夜忧叹」「五月渡泸」「庶竭驽钝」）。

## 这一轮：文档里的数字不再手抄（新护栏 `sync-doc-numbers.py`）

上面这几段暴露了一件比错字更烦人的事：**文档里的数字是抄来的，抄来的数字会过期**。
护栏「文档里写死的数字与产物一致」只查不改——于是每改一次正文，繁体派生的计数就动一下，文档立刻过期，护栏变红，
整条链重跑一遍（12 分钟），只为把三个数字手抄对一遍。这一轮为这件事重跑了三遍。

现在 `tools/sync-doc-numbers.py` 做这件事：读产物、按当场的数改文档里的数字，**句子一个字不动**。
它用的匹配器就是 audit-content 里的 `doc_number_actuals`（本轮把那段从护栏里抽出来，只留这一份）——
改的那套和查的那套必须是同一份口径，否则链条永远跟自己打架。

自检带 10 个坏例子：过期的没改全、本来对的被误改、产物不在场还硬写数字、文档里没有的数字被凭空添上、
不在匹配表里的数字（「252 篇」这种）被动了、同一处出现两次只改一遍、句子被顺手改了、文档为 None 还继续——都试到。
另外做了破坏测试：把实现改坏四处（什么都不改 / 产物不在场也继续 / None 也继续 / 误改对的数字），自检分别报 4、1、1、1 个坏例子。

它接进了链条（本地链条 52 步：实跑排在 `audit-content` 之前）与 CI（28 项自检里多这一项，CI 只跑自检、不改文件）。
护栏本身保留：文档里的数字对不上照样红——只是从此不需要我手抄。

`apply-textbook-status` 9 个，含「不许把同名另一篇抹成收录」「两条来源都出自同一镜像不许放行」），
`validate.py` 另加 2 个（园地两条来源核过了却写「未收」、裁定表自己坏了却默认放行，都要报）。

江畔独步寻花有一条来源把它放在六年级上册语文园地一（2024 修订教材，21cnjy 26034935），与另两条不一致：
仓里按两条落四年级下册，冲突写进裁定表与篇内，不当没看见。

### 这一轮把「只有一条来源」那一档清空：35 篇升格，一处假的「同名另一篇」被撤（本轮改）

「统编教材收了（只有一条来源）」当时有 34 篇，另有 1 篇顶着「同名另一篇」（梅花）——35 篇的证据都只是那个镜像。
本轮逐条给它们找第二条独立来源，写进 `data/garden-rulings.json`（当场数 38 条裁定，含先前的 3 条）。
第二条来源用的是 `zy.21cnjy.com` 的统编古诗文整理合集与 `xiaoxue.koolearn.com` 的教材页，每条在裁定表里写明 URL，
门槛照旧：那个镜像最多算一条。核对表当场数（`data/textbook-attestations.json` 的 `stats`）：
`garden-attested` 3 → 38 条，`garden-mirror-only` 35 → 0 条。

那 35 篇的册次都没动（教材把它们放在同一册的语文园地，不在课文目录里），改的只是「教材收没收」这句话：
站点原先对 34 篇什么都没说、对梅花说「收的是同名另一篇」，现在 35 篇都写明栏目与两条来源。

梅花那条是本轮查出来的**假话**。原先的依据是教材目录表里五年级下册有一篇「同名」的——那一篇叫《梅花魂》，
是另一篇课文，不是另一首《梅花》。错在 `build-textbook-lessons.py` 允许前缀互含（「梅花」⊂「梅花魂」）
就把同名候选收进 `titleCollision`，正文一句都对不上（0/2）也照样写。这句话的代价很具体：
它告诉学生「教材收了另一首《梅花》」，而教材里没有——它把「我们没找到这一课」说成了「教材收了另一首」。
现在那句结论只许由整名对下（`exact_same_title`）；前缀候选照旧留着当候选、由正文定夺，
落不到同名另一篇的退回与「同名没有」同一条路（园地裁定或「目录里没有」），两条路都不许写成同名另一篇。
当场数：`titleCollision` 3 → 2 条（相见欢、凉州词——教材里那两篇确实同名不同作）。

`build-textbook-lessons.py` 先前一个坏例子都没有，现在配 7 个（前缀同名不许算、真同名不许误杀、
课号与自读星号与「（节选）」必须剥掉、函数挂在文件里却没接进 `audit()` 也要报），本地链条与 CI 各加一步。
它上线当天就被自己的自检抓到一次：`must()` 只打印不计数，把整名对改成前缀互含后自检照样 exit 0——
补上计数才当场失败（坏例1、坏例4 冒出来）。**空过的检查比没有检查更危险**，这一条又一次是真的。

`apply-volume-findings.py` 那道「裁定表说的册次必须与园地表对得上」也自己写了一份剥括号的规则，
与 `check-textbook.py` 的 `garden_name` 不是一条口径：它把「悯农（其二）」剥成「悯农」，
于是 5 篇被它拦下（悯农其一、悯农其二、古朗月行、赋得古原草送别、观书有感）。
现在它按路径加载 `check-textbook.py`，用同一份口径（篇名对齐只有一份）。
顺带把两条裁定表的篇名按园地表的写法改正（观书有感其一、回乡偶书）——被核对的是园地表，裁定表跟着它写。
它的自检 19 → 22 个坏例子（编号不许被抹平、也不许把对得上的认成没有）。

## 教材状态从五档扩到七档：「只有一条来源」和「没找到」是两回事（本轮改）

原先五档里「统编教材未收（课标要求）」被两类篇目共用。一类确实是课标要背、统编教材课本里没有这一课；
另一类既不在课标 135 篇里、我们也没在教材里找到（一年级下册《相思》）——它顶着「课标要求」四个字，
等于替课标作了一个课标没作过的声明。另有 35 篇在同一册的语文园地页里明明有（咏鹅、忆江南、舟夜书所见……），
只因为那条来源只是那个镜像，就被写成「未收」：站点告诉学生「教材没有这一课」，镜像却说教材收了。

新增两档。标签清单只写一份（`validate.py` 的 `TEXTBOOK_LABELS`），`apply-textbook-status.py` 的 `ALLOWED`、
台账计数、这份文档都从它来；谁手抄一份、漏了一档，自检当场报。

| 标签 | 当场数 | 这一档说的是 |
|---|---|---|
| 统编教材收了（只有一条来源） | 0 | 同一册的语文园地页里有这一篇，可手上那条来源只是那个镜像：不许升格成「收录」（一条不够），也不许反过来说「未收」。说的是证据的份数，不是教材有没有 |
| 统编教材里没找到这一课 | 1 | 23 册课文目录与抽到的语文园地页里都没有，而且它不是课标篇目。说的是「我们没找到」，不是「教材没有」 |

七档当场数：收录 223 / 只有一条来源 0 / 未收（课标要求）17 / 收在别的课里 8 / 同名另一篇 2 / 没找到 1 / 收一部分 1 = 252。
（这一行本轮动过一次：34 篇「只有一条来源」逐条查到第二条来源后升格成「收录」，
梅花那条假的「同名另一篇」被撤——见上面「语文园地里的篇目」那一节。）
「未收（课标要求）」从 52 降到 17，剩下的 17 条全是课标篇目（9 条高中 + 8 条选修默写），这一档从此只说课标说过的事。

「没找到」不能只是一句结论。新表 `data/absence-checks.json` 登记查了什么：《相思》那条写明小学 11 册课文目录
（781 条）里没有同名课文、全仓目录里带「相思」的只有五年级上册《长相思》（纳兰性德，另一篇）、
一年级下册 8 页语文园地逐页读过（园地四 是成语、园地六 是气象谚语、园地七 是《荀子》/陈寿/董其昌 名言），
八页的日积月累里没有王维《相思》。`validate.py` 的 `absence_record_problems` 规定：篇内写这一档，

剩下 9 条 `lesson-not-found` 是高中课标篇目。它们的说法现在自带边界（`check-textbook.py` 的 `absence_note`）：
「同学段所有册的课文目录里都没有同名课文」——语文园地那一档只抽了小学 12 册，高中的园地页我们没核过，
note 就写明「高中的园地页没核过，这句话只覆盖课文目录」；小学那 12 册里也有 29 页只列了栏目头、没列篇名，
note 同样写明「找不到不等于没有」。谁把边界摘掉，自检当场报（坏例 19f / 19g / 19h）。

自检规模当场数：`check-textbook.py` 106 个坏例子、`apply-textbook-status.py` 44 个、`apply-volume-findings.py` 22 个、`build-textbook-lessons.py` 7 个（教材拓展不许冒领「课标要求」、
课标篇目不许写成「没找到」、一条来源不许升格也不许说没收、七档每一档都得有规则能产出）、
`validate.py` 教材状态 19 个 + 登记簿 6 个。把 `absence_record_problems` 改成永远不报，自检当场失败（6 处坏例子全冒出来）；
把 `status_of` 的园地分支改成直接「收录」，`apply-textbook-status --selftest` 当场失败。

顺带揪出一句错话：江畔独步寻花篇内原先写「教材与课标要背的是其六」。课标列的是
「江畔独步寻花（黄师塔前江水东）」，仓内正文也正是这一首；维基文库《江畔獨步尋花七絶句》把七首按序排，

## （续五）比对表里的字，和「还没核对」这句假话

这一轮先修的是比对工具自己。

**一、norm 把字弄丢过两次。** 教材核对先把两边的标点都剥掉再比。旧写法是 `[^一-鿿]`——只保 U+4E00–U+9FFF，
于是「䜩」(U+4729)、「𫐐」(U+2B510)、「𪩘」(U+2A658)、「𫘝𫘨」在仓内这一侧被抹掉：比对结果就成了
「教材那边多出一个字」，而真相是两边各写了一个不同的字。改成「凡是非字母都剥」又翻第二次车：
教材页里带注音，拼音（yǒng、xī、ēng、tuó）被留在比对里，锚点落在拼音上，「永和九年」对不上「yǒng 和九年」。
现在只认汉字区：基本块 + 扩展 A–H + 兼容表意文字 + 〇。坏例子当场数到 135 个，包括「䜩 不许被抹掉」
和「拼音不许留在比对里当锚」两条。

**二、单字出入与残影分开数。** 以前只报「X/Y 句对上」，剩下的那一截到底是差在一个字上、还是段落边界
与教材夹注造成的错位，台账里分不出来。现在每处差异先剥公共前后缀、再看第一处真正不同的地方，分成
单字出入 / 教材那边多出一段 / 我们这篇教材里没有 / 说不清的一大段。当场数：**16 篇 partial，单字出入 18 处，残影 64 处**。

（这一节的数字是**按行**比出来的，已被下一节按句比出来的 17／16／31 取代。）

**三、每一处单字出入都必须有话交代（新护栏）。** validate 现在要求：核对表记下的每一处单字出入，
篇内「异文」或「收录范围」里必须有一行同时提到两边的字。写在「注释」里不算，只提一边的字不算。
这条一跑就抓到三处没人交代的，全补上了：

- 劝学：仓内「𫐐」／统编「輮」（两处），出处 https://yw.suyang123.com/gaozhong/bixiushang/30117_langdu.html
- 短歌行：仓内「䜩」／统编「讌」，出处 https://yw.suyang123.com/gaozhong/bixiushang/13095_langdu.html
- 过秦论：仓内「宁」／统编「甯」，出处 https://yw.suyang123.com/gaozhong/xuanxiuzhong/30416_langdu.html

三处都是同一个字的不同写法，按口径只登记不改正文。其余 15 处（三峡 𪩘／巘、谏逐客书 𫘝𫘨／駃騠、
谏太宗十思疏 治／理·以／因、归去来兮辞 遊／邱、屈原列传 平／原·眜／眛·覆／复·混／皆·馀／余·观／过）
原来就在「异文」里写着，这条护栏把它们钉住，以后不许再漏。

**四、39 处「统编教材用字尚未逐本核对（P3 待办）」被换掉。** 这句话在 38 篇里留着，可教材核对早就把
每一句比过了——留着它就是句假话，读者以为那一篇没查。新工具 `tools/apply-textbook-scope.py` 按核对表
当场数出来的句数生成那句话（哪一册、哪一课、几句可比、几句对上、几处单字出入、出处链接），
核对表里没有结论的篇目它直接报错、不许编。validate 从此禁止「P3 待办」「尚未逐本核对」这两个短语；
满江红那种诚实登记的真待办（点名登记在 data/known-defects.json）不在禁止之列。

**破坏试验**：把过秦论那句话改回「尚未逐本核对（P3 待办）」——当场被抓住；把劝学「𫐐／輮」那条异文整条删掉
——当场被抓住；把凉州词的「收录范围」小节改名——当场被抓住；把册次只留在出处链接里——当场被抓住。
四次都原样恢复、字节一致。

## （续六）比的是句子不是行，窗口不许自己跑偏

上一节把差异分成「单字出入 / 残影」，但比对单位还是**行**，而且窗口是拿「最长公共片段」当锚开出来的。
两处都出过事：

**一、行不是合适的单位。** 教材把两三行并成一段时，我们这一整段被当成一句话去比，「山之僧**曰**智仙也」
只差一个「曰」就被埋在那一大段里，台账只说「这一段没对上」。另外名句小节里的句子在全文里又出现一次，
分母被撑大一倍——《观沧海》12 句其实只有 6 句。现在比对单位是**句**：按 。？！； 拆开、按剥掉标点后的
字面去重，坏例子 24a–24g 钉住「去重后是 2 句不是 3 句」「整段要拆成 4 句」。

**二、窗口会跑偏，跑偏就造出假出入。** 旧写法从锚的位置开窗口，锚一偏整窗就偏：谏逐客书「今弃击瓮而就郑卫」
被记成「仓内多了『今弃』」——那是窗口起点错了，不是文字分歧。**假的字面出入比没记更坏**，它会让人去改
一个本来没错的正文。现在窗口在教材里滑一遍（只试首尾三字出现过的位置）取最像的那个，再把窗口头尾掉进来的
「教材多出一段」砍掉——只有句子中间的差异才算数。坏例子 25a–25f、26a–26d 钉住这两条。

**三、句子只差一个字时，不许判成「教材里完全没有」。** 锚门槛原来是四个字，「山之僧曰智仙也」这种句子最长
公共片段恰好只有三个字，就被整句扔进残影。门槛降到三个字，并新增一档**缺一边**：教材那边没有的字
（或多出来的字）单独记下来。护栏也跟着放宽——以前只提一边的字不算交代，现在哪边非空，那一边的字就必须
出现在同一行里。

**当场数**（16 篇 partial）：**单字出入 17 处、缺一边 16 处、残影 31 处**。残影里离骚 28 处、北冥有鱼 3 处，
全是统编节选范围（教材没收的那几段），不是用字出入。工具自检坏例子从 135 涨到 152 个。

**四、新护栏：篇内那句「已逐句核过」的数字必须跟核对表一致。** 核对表更新了、篇内那句话没跟着更新，
读者读到的就是旧结论——旧结论比没结论更容易被当真。这条一跑就抓到一处真错：《渔家傲》（天接云涛连晓雾，
八年级上册课外诵读）篇内写着「本篇 5 句可比，5 句与统编九年级下册『渔家傲·秋思』一致」并挂着另一首的链接——
同名两首被按篇名找核对结论挑错了。现在按 frontmatter 的 id 找，那句话已改成 6/6 与正确的课文页。
validate 新增四组自检共 29 个坏例子（同名撞车 7、字面出入 12、过期待办 4、核对数字 6）；下一轮把字面出入那一组从 12 加到 17（见（续八））；
`tools/apply-textbook-scope.py` 自检 20 个坏例子。

**五、按句比对后新显形的 11 处，逐条查过教材页原文再写进「异文」。** 正文一律不动（只有镜像一条来源）：

- 醉翁亭记：仓内「山之僧**曰**智仙也」／统编「山之僧智仙也」
- 邹忌讽齐王纳谏：统编「问之**客曰**：『吾与徐公孰美？』」，仓内没有「客曰」
- 谏逐客书：统编「快**耳**者」，仓内作「快耳目者」；统编「今弃击瓮**叩缶**而就《郑》《卫》」，仓内没有「叩缶」
