# 贡献规范

感谢参与！这份内容直接关系到孩子的学习质量，也关系到我们的版权安全，
所以有几条硬性要求。

## 快速开始

```bash
git clone https://github.com/diuci/k12-chinese-poetry.git
cd k12-chinese-poetry
python tools/validate.py# 提交前必跑，全绿才能提交
```

无需 `pip install`，工具链只用 Python 3 标准库。

## 硬性要求（违反会被 CI 拦下）

| # | 要求 | 为什么 |
|---|------|--------|
| 1 | `tools/validate.py` 必须全绿 | 数据错误的护栏 |
| 2 | 只能使用**公有领域**作品 | 法律风险为0 是硬指标 |
| 3 | 注释/译文/赏析**必须自己写** | 不能抄商业站点的内容 |
| 4 | 正文用字以**人教社统编教材**为准 | 各地教材用字有差异 |
| 5 | 新增篇目要有`source` 与 `license` | 台账完整性 |

## 我想校订一个字

这是最常见的贡献，也是最有价值的。

### 1. 找到文件

篇目按 `poems/学段/册次/篇名.md` 组织，例如
`poems/小学/三年级下册/清明.md`。

### 2. 改正文

正文是 `## 注释` 之前、带标点的那几行。**改字词，不要动格式。**

### 3. 更新用字校订记录

如果这个字容易错（教材与常见版本不同），在 `PROVENANCE.md` 的
「用字校订记录」表里加一行：

| 篇目 | 教材用字 | 常见误用 | 说明 |
|---|---|---|---|
| 元日 | 曈曈日 | 瞳瞳 | 「曈」为日字旁 |

### 4. 跑校验

```bash
python tools/validate.py
```

若报「每联应为 N 字」，说明改动影响了字数。若是**已知的不规则**
（如《咏鹅》首句「鹅鹅鹅」），在 frontmatter 加 `irregular:` 说明即可。

### 5. 提交

```bash
git add poems/小学/三年级下册/清明.md PROVENANCE.md
git commit -m "fix(清明): 校订「遥知兄弟登高处」的「插」为「茱萸」用字"
```

## 我想补注释 / 译文 / 赏析

篇目里这三节目前是占位：

```markdown
## 注释
- （待补：字词注释）

## 译文
（待补：白话译文）

## 赏析
（待补：文学常识与赏析）
```

请把它们替换成真正的内容。要求：

- **注释**：解释难字、生僻词、典故。简明，不必面面俱到。
- **译文**：现代汉语。逐句对应，保留原文的节奏感。
- **赏析**：说清"为什么好"，而非复述"写了什么"。可参考已有的赏析维度
  （写作背景 / 表达手法 / 情感 / 语言特色）。

⚠️ **不要从商业网站复制**。自己写，或在充分理解后重新表达。

## 我想新增一篇

### 前置：确认它在收录范围内

本仓只收两类：

1. **课标 135 篇** —— 清单见 [syllabus-2022.md](syllabus-2022.md)
2. **教材拓展** —— 统编教材里有、但不在课标 135 篇内的篇目，
   需先在 `syllabus-2022.md` 末尾的「教材内但不在课标」附表登记

不在这两类里的篇目不会被收录，因为本仓要与课堂进度对齐。

### 步骤

1. 在正确的 `poems/学段/册次/` 下新建 `<篇名>.md`
2. 复制已有篇目的 frontmatter 结构，逐字段填写
3. 正文写全，带标点
4. `pairs` 按整句两两配对（如 4 句 → `0-1, 2-3`）
5. 补 `source`（如 `S3+S1+S2`）与 `license: public-domain`
6. 跑 `python tools/validate.py`，全绿再提交

### 注意 id 命名

`id` 是**永久标识**，游戏内与联机同步都依赖它，一旦发布不再更改。

- 用小写拼音或英文，如 `chunxiao`、`jueju-huangli`
- 同名篇目加后缀消歧，如 `jueju-huangli`（两个黄鹂）/ `jueju-chiri`（迟日江山丽）
- 见过的 `id` 绝不重复使用

## 数据从哪来

正文主要参考 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)（MIT 许可），
再用**人教社教材**核对用字。详细来源与许可边界见 [sources.md](sources.md)。

**特别注意**：chinese-poetry 的数据来自网络爬取，可能有异文。
若发现与教材不一致，**以教材为准**。

## 版权红线

🚫 **不得**收录仍在著作权保护期内的作品全文。
例如秋瑾《满江红》（1903 年发表，作者 1907 年遇害）——
如需收录，先放入 [`pending/`](pending/INDEX.md) 并在 `INDEX.md` 登记，
不要直接放进 `poems/`。校验脚本会拦截。

🚫 **不得**复制商业站点的译文、赏析、注释。
本仓的注释/译文/赏析必须是自己写的。

## 代码风格

工具脚本（`tools/*.py`）：

- Python 3，纯标准库
- **2 空格缩进**，单引号（与游戏主仓 `inkwave-main` 保持一致）
- 所有文件读写显式 `encoding='utf-8'` —— Windows 下 Python 默认 GBK 会崩
- 注释解释**为什么**，不复述代码在做什么
- 校验失败要给出**可操作的**错误信息（错在哪、怎么改）

