### 为什么严格按课标收

孩子在学校学的，就是课标列的这些。收进来等于给家长省掉筛选的活。
同时课标也划清了"必须会背"的边界——避免让孩子把时间花在超纲内容上。

### 口径差异说明

课标**正文**第四学段（7–9 年级）表述为"背诵优秀诗文 80 篇（段）"，
**附录 1** 列出的是 60 篇（段）。两者层级不同：

- **正文** = 总量要求（学段内应达到的积累量）
- **附录** = 具体推荐篇目清单

本仓以**附录 1** 为准，因为它给出了可直接操作的篇目列表。

## 学习路径建议

### 先读，再理解，最后背

每篇的结构是 `原文 → 注释 → 译文 → 赏析`。建议顺序：

1. **出声读原文**三遍，读顺为止
2. **看注释**解决生僻字
3. **看译文**确认自己理解对了
4. **读赏析**理解"为什么好"

不要一上来就看译文。**自己猜出来的意思，记得更牢。**

### 按年龄分层

| 学段 | 重点 | 方法 |
|---|---|---|
| 一二年级 | **诵读** | 出声读、接下句，重语感不求理解 |
| 三四年级 | **画面** | 问"你看到什么"，不問"什么意思" |
| 五六年级 | **手法** | 先感受再给名字（对仗、比喻、拟人） |
| 初中 | **意蕴** | 讲背景、讲典故、讲一脉相承 |

### 用游戏的方式记

《丢词大作战》（[diuci.com](https://diuci.com)）把诗词变成涂地射击：

- 涂一块地**不算占下**，必须在这块地上写下一句诗
- 相邻两块地写**同一首诗的上下句** → 涂地收益**翻倍**

要玩得好就得真记住。当游戏，不当作业。

详见[家长指南](guide-for-parents.md)。
