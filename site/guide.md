# 家长指南

这是一份给孩子用的古诗文库。我们希望它**不只是题库**，而是能真正帮孩子理解和记住这些诗的地方。

## 先说一件事：为什么要按课标收

教育部《义务教育语文课程标准（2022年版）》附录 1 推荐了 **135 篇（段）** 古诗文
（小学 75 + 初中 60），高中课标另有 **72 篇**，合计 **207 篇**。

我们只收这些，另加少量统编教材里出现但课标未列的篇目（单独标注为「教材拓展」）。
这样你打开这个库，看到的就是孩子学校要学的范围——**不用在茫茫诗海里自己筛**。

> **口径提醒**：义务教育课标正文里7–9 年级写的是「背诵优秀诗文 80 篇（段）」，
> 附录 1 列的是 60 篇（段）。两者不矛盾：正文是总量要求，附录是具体篇目清单。
> 我们以附录 1 为准，因为它列出了具体篇目。

## 怎么用

### 一、按册次往下推进

目录是「小学 → 初中 → 高中」，再按册次分，和孩子的课本进度同步。他学到哪，就读到哪。

### 二、先读，再理解，最后背

每篇的结构是一样的：

```
原文 → 注释 → 译文 → 赏析
```

建议顺序：

1. **出声读原文**三遍，读顺为止
2. **看注释**解决生僻字
3. **看译文**确认自己理解对了
4. **读赏析**理解「为什么好」

**不要一上来就看译文**。孩子自己猜出来的意思，记得更牢。

### 三、拼音

每篇正文都带拼音注音（ ruby 标注），孩子可以自己对照。
低年级认字量有限时，拼音能显著降低阅读门槛。

::: tip
打印出来时拼音会自动保留（打印样式专门处理过）。
:::

## 几个具体的建议

### 低年级（一二年级）

以**诵读**为主，不必要求理解。「静夜思」「春晓」这类孩子天生能背，重点是让他感到「念起来好听」。

**推荐玩法**：你说上句，他接下句。《江南》尤其适合——「鱼戏莲叶东/西/南/北」，
接完四句再倒着接一遍。

### 中年级（三四年级）

开始讲**画面**。问「你看到什么」，而不是「这首诗什么意思」。

> 《山行》：如果你是坐在这辆车里往外看，先看到什么？

### 高年级（五六年级 + 初中）

可以讲**手法**了。对仗、比喻、拟人、用典——这些不需要术语，先让他们感受到，再给名字。

> 《咏柳》：「碧玉妆成一树高，万条垂下绿丝绦」——柳树像什么？碧玉还是丝绦？
> 为什么先写「妆成」？

### 高中

文言文开始出现长篇。我们的处理方式是**抽出课标要求背诵的名句**单独呈现，
并在篇目里标注了背诵要求（全文背 / 背段落 / 背名句 / 理解为主），
方便按考试要求取舍。

## 关于游戏

我们做了个游戏叫《丢词大作战》，把这些诗变成了涂地射击游戏（[diuci.com](https://diuci.com)）。玩法是：

- 你在地面上涂一块地
- 但**光涂没用**——你得在这块地上「写」下一句诗，这块地才算「占下」
- 如果相邻两块地写的是**同一首诗的上下句**，涂地收益**翻倍**

所以要玩得高分，得真的把诗记住。这不是游戏化包装，是把「背诵」这个动作变成了有即时反馈的事。

**建议**：当游戏，不当作业。孩子愿意玩的时候，背诗会变得容易很多。

## 常见问题

**Q: 课文版本对不上怎么办？**
各地教材版本不同（统编版、苏教版、北师大版等），篇目基本一致，但**用字**可能有差异
（如「树阴/树荫」「曈曈/瞳瞳」）。我们统一以**人教社统编版**为准。
如果孩子学校用的是其他版本，发现不一致可以告诉我们。

**Q: 为什么有的诗标注「教材拓展」？**
因为它出现在孩子的课本里，但不在课标 207 篇内。我们保留并标注，方便你区分
「课标必背」和「课本里学的」两类要求。

**Q: 秋瑾的《满江红》为什么没有？**
它发表于 1903 年，作者秋瑾 1907 年遇害，著作权保护期还没结束。
我们**不收录保护期内的作品全文**，这是为了避免法律风险。

**Q: 可以打印吗？**
可以。点顶部「打印版」，或直接对任意篇目按 <kbd>Ctrl</kbd>+<kbd>P</kbd>——
打印样式会隐藏导航、保留拼音与注释译文。

**Q: 可以拿来商用吗？**
诗文原文是公有领域，随便用。我们写的注释、译文、赏析采用
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)，
**使用时署名「来源：k12-chinese-poetry / 丢词大作战」** 即可。

- **难度标记** 1–5 可用来做分层作业
